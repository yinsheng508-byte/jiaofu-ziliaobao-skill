# 第二章　基期量
^ 问题三步走：圈时间、判题型、定主体
## 一、基期的计算
### 1、给现期、变化量（增长量、减少量）
- **公式（高减低加）**：~~基期＝现期－增长量~~
^ ~~基期＝现期＋减少量~~
:::印
{点}例：2017 年末，全国铁路营业里程达到 12.7 万公里，比上年增长 2.4%，其中高铁营业里程 2.5 万公里。~~全国铁路路网密度 132.2 公里/万平方公里，比上年增加 3.0 公里/万平方公里~~。
【例 1】（2019 广东选调）__2016 年末__，我国铁路路网密度是多少公里/万平方公里？
:::
:::例题
A. 126.2
*B. 129.2
C. 130.2
D. 135.2
公式：基期＝现期－增长量
基期＝132.2－3＝129.2
（划线减法）
:::

### 3、给现期、增长率
- ==考法一：== 求基期
**公式**：基期＝{分|现期|1＋增长率}
速算：~~截位直除~~、~~化除为乘~~、~~特殊数字~~
:::例题
A. 65.33
*B. 67.65
C. 94.99
D. 98.35
公式：基期＝{分|现期|1＋增长率}＝{分|80.16|1＋18.5%}＝67
:::
==速算技巧：化除为乘== （先消百分号，再计算）
当 |r|≤5% 时，{分|A|1＋r} ≈ A＊（1－r）＝**A－A＊r**
:::框
注：r“＋”，0%＜r≤5%　　**直除更快**
　　r“－”，－5%＜r≤0%　**化除为乘更快**
反例：(1) 选项**首位相同**，**第二位**也相同
　　　(2) **4%＜|r|≤5%**　　｝只能直除
:::
