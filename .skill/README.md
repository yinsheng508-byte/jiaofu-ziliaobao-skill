# 教辅资料包 skill

把你手里的**参考资料**（同行成品、截图、讲义、真题）、**电子课本**和**自己整理的资料**，用 AI 整合升级成一份更清晰、更完整、内容更丰富的**原创资料产品**：Word 精排 + PDF，或者 A4 手写风笔记。学生、家长、老师、大学生、考研、考公、教资、求职……各类资料都能做。Mac 和 Windows 都能用。

## 它怎么保证质量

- **知识不编**：知识点、题目、答案都来自你给的资料和课本，每一块标了出处；资料里没有的标【缺】交给你
- **内容更丰富**：几份资料互相补全，做成对比表、归纳、易错汇总；每页排得饱满
- **像老师在 Word 里精调**：真正的 Word 样式、目录、表格、页眉页脚，打开就能改，不是机器导出的网页感
- **不留原作者信息**：原资料的作者名、店铺名、水印、联系方式全部清掉，文件属性也会清空
- **自动检查**：出处、AI 腔、原作者信息、填充率、各版本页数是否一致，不过关不交付

## 第一次使用

1. 解压得到「教辅资料包制作 skills」文件夹（`.skill/` 是 skill 本体；Mac 上按 Cmd+Shift+. 显示隐藏文件夹）
2. 用 Claude Code 打开这个文件夹，说：**「按 .skill/references/安装配置.md 帮我把环境配好」**
3. AI 会按你的系统装好依赖、检查 Word / LibreOffice / 浏览器、装好 `/手写笔记` 快捷指令并试跑；要你自己做的（输密码、装 Office、填令牌）它会停下来告诉你

## 怎么用

在 `输入资料/` 里给这份资料包建一个文件夹（复制「新资料包」模板改名），放三样东西：

| 子文件夹 | 放什么 |
|---|---|
| `1_教材课本/` | 教材或电子课本，用来核对内容 |
| `2_对标资料/` | 收集的对标资料、你自己整理的资料，这是内容来源 |
| `3_参考版式/` | 你想要的排版样子，图片或文档都行 |

然后在 Claude Code 里说「把 输入资料/<资料包名称> 做成资料包」。全程只停三次：

1. **出规划**（`1_规划/`）：做成什么样、分几个版本、每部分用哪份资料、缺什么、用什么风格
2. **出样张**（`2_样张/样章/`）：排好版的第一章，满意了其余章节照着做完，中间不打扰你
3. **出成品**（`3_成品/`）：全部 Word / PDF + 检查结果

手写笔记：说「/手写笔记 <资料路径或项目>」。
商品主图 / 详情图：说「/商品主图 <产品主题或项目> <店铺名>」（或简写 /主图），出 3 张 3:4 上架图，有 5 套配色模板可选；店铺名每次现场提供，不会存进任何文件。
做完可以自动传到飞书知识库或 ima 知识库（要先配置，见安装配置第六节）。

每做完一类新资料，生成工具会沉淀成**模板**，下次同类资料直接套用，越用越快。第一次用时 AI 会问你几个习惯（常做什么资料、喜欢什么样式），存进 `偏好.md`，以后不再重复问。

## 文件夹里有什么

```
教辅资料包制作 skills/
  输入资料/        你的资料放这里
  输出项目/        每个资料包一个文件夹，里面分三个阶段：
                     1_规划/（需求、素材、方案）  2_样张/（内容稿、排版、第一章样章）  3_成品/（最终 Word / PDF，重点看这个）
  偏好.md          你的习惯（第一次用时生成）
  .skill/
    SKILL.md       工作流程（给 AI 看）
    README.md      本文件
    references/    通用规范：需求与方案、取材、内容、文风、视觉、质检与交付、模板指南、安装配置
    templates/     模板库：考点答题模板、英语语法手册、知识手册（背诵默写）、手写笔记……
    assets/        主题库（8 套配色风格和效果图）、手写笔记的字体样式样张
    config/        检查词表、经典引擎的排版参数
    scripts/       脚本，统一入口 run.py
    shortcuts/     快捷指令：/手写笔记  /商品主图  /主图
```

## 常用命令

在 `.skill` 文件夹里运行；Windows 把 `python3` 换成 `python`。平时让 AI 跑就行：

| 命令 | 作用 |
|---|---|
| `python3 scripts/run.py setup` | 首次安装 |
| `python3 scripts/run.py doctor` | 环境自检 |
| `python3 scripts/run.py template list` | 看有哪些模板 |
| `python3 scripts/run.py theme list` | 看有哪些主题 |
| `python3 scripts/run.py pdf <项目>` | 在 Word 里改过之后重新导出 PDF |
| `python3 scripts/run.py audit <项目>` | 交付前检查原作者信息 |

**字体授权**：手写笔记的 6 款字体随包自带，有几款来自网店打包，商用前请自己确认授权。
