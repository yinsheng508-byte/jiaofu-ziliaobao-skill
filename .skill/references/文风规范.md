## 一、总原则

整合升级会重写讲解，最容易出 AI 腔。写的时候想象：一个有经验的老师在讲台上讲，或在讲义旁边批注。**短句、具体、说人话**；能用素材原话的优先用原话。

## 二、禁用清单（`check` 按 config/检查词表.json 查，error 必须改）

| 机器腔 | 例子 | 改成 |
|---|---|---|
| AI 连接词 | 首先、其次、综上所述、值得注意的是、总而言之、本质上 | 删掉，直接说事 |
| 套话收尾 | ……即可。 | 删掉，或写具体：「把文中写声音的两个词抄下来。」 |
| 分析报告腔 | 从多个维度、关键在于、底层逻辑、赋能、抓手 | 换成老师和学生说话的词 |
| 「不是……而是……」排比 | 不是 X，而是 Y；不仅……更…… 连用 | 直接说 Y |
| 讲解里用箭头串流程 | 定类型 → 找原文 → 对选项 | 1.先看问的是什么。2.回到原文找。3.对照选项选。 |
| 用「＝」下定义 | 紫＝问法 | 用句子说 |
| 编号式小标题 | 陷阱①张冠李戴： | 自然标签：「人物换了：」 |
| 生造词 | 速联、超级记忆、黄金法则 | 用普通说法 |
| 营销腔 | 全网最全、名师、必考、逆袭、躺赢 | 删掉（来源里原话除外） |
| 自我说明 | 以下是、本资料包、（试样）、【颜色导读】 | 删掉，成品里不出现制作过程 |
| 破折号滥用 | 一段里出现两个以上「——」 | 改成逗号或句号（来源行「——《课文名》」除外） |

例外：练习题本身的流程填空框（「情节梳理：____→____→____」）可以用箭头。

## 三、反 AI 文风分层自查（每章写完过一遍）

| 层 | 查什么 | 怎么改 |
|---|---|---|
| 1 用词 | 第二节的词；成堆的形容词（「非常重要的关键核心」） | 删 |
| 2 句式 | 每句都一样长；连续三句同一个开头；「不是……而是……」 | 长短句交错，换开头 |
| 3 结构 | 每段都是「总—分—总」；每个知识点都配一句空泛总结 | 去掉空泛总结，留具体内容 |
| 4 语气 | 过于客气、过于激昂、对读者说教 | 平实，像面对面讲 |
| 5 事实 | 为了顺口改了数字、年代、原句 | **恢复原样**；文风修改不许动事实 |

## 四、中文排版规则（`check` 查）

- 中文用全角标点：，。、；：？！“”（）《》；英文句子、公式里用半角
- 数字用半角（1000，不写 １０００）；不重复用标点（！！、？！）
- 专有名词大小写正确（PEP、GitHub、DNA）；不用不规范缩写
- 中文和英文、数字之间加不加空格：**一本书里统一**，照参考；没有参考时英语学科加、其他学科不加
- 引号贴紧文字，前后不留空格（用“小小”来形容）
- 单位：数值和单位之间不空格的情况（90°、15%）照国标写法

## 五、各用户群的语气

| 用户群 | 语气 | 例 |
|---|---|---|
| 小学家长 / 小学生 | 亲切、短句，孩子能照抄 | 「答：我认为……，从……中可以看出。」 |
| 初中、高中 | 简洁、考试口吻 | 「考查……，故选 B。」 |
| 老师 | 专业、规范 | 「教学建议：……」 |
| 大学生、考研 | 学术、简洁 | 「名词解释：……」 |
| 考公、教资、职业资格 | 干练、直接给方法 | 「看到……，先……」 |
| 求职 | 职场、自然 | 「可以这样回答：……」 |

参考资料的语气和这里冲突时，照参考。

## 六、自查办法

- `$RUN check <项目>` 查第二、四节
- 每章挑三段**读出声**：读着像说明书、产品文档、营销号的地方改掉
- 新发现的机器腔补进 `config/检查词表.json` 和本文件第二节
