# 资料框架

搭目录方案时先按资料类型选框架，再按教材单元铺开。五类框架（知识清单下另有「英语语法手册」细分）共用一套排版（排版规范.md）和一套标记（标记写法.md），区别只在「每个单元里放什么栏目」。
**框架是骨架，内容仍然全部来自素材**；素材撑不起某个栏目就去掉这个栏目或标【缺】，不硬编。

## 一、考点答题模板（主参照品）

适合：阅读理解、作文、古诗文、英语阅读/完形这类「有题型、有答法」的专题。
参照品：一份市售的《三上语文阅读理解考点与答题模板》，8 单元 23 考点，每单元 5 篇练习，100 页。

```
第 1 页：彩色总标题 + 目录（单元 / 考点 / 练习篇目）
# 第一单元（单元主题）              ← 教材单元顺序
> 单元语文要素（教材原话）
## 考点 1：……                      ← 全书连续编号，一个单元 1–4 个
【常见问法】  考卷原话，1–3 种问法
【答题思路】  分点短句；可带分类小标签（!有动态感的词语：……）
【答题模板】  ××/……占位，括号给可选词；可按角度分（1）（2）
例：题干（分值）
| 课文原文段落
——《课文名》
答：示范答案
## 考点 2：……
### 单元练习篇目 1 ~ 5               ← 每单元篇数尽量一致
| 短文
（有改动）
一、/1.2.3. 题目（分值），选项，[横线]
# 参考答案
## 第一单元
### 一、篇目
1.考点：…… / 详细答题思路：…… / 参考答案：……
```

篇幅参考：讲解每考点 1–2 页，练习每篇 1–1.5 页，答案每篇约半页。

## 二、知识清单 / 知识点手册

适合：小初高各科知识点汇总、期中期末复习提纲、小四门（史地政生）背诵手册、英语单词句型。

```
# 第一单元（单元主题） / # 第 1 课 ……
> 本单元要掌握的内容（教材或素材原话）
## 知识点 1：……
【知识点】  核心概念、定义、公式、时间地点人物（素材原文）
【易错点】  素材里提到的易混、易错
【方法】    记忆口诀、解题方法（有就放，没有不编）
例：典型题（素材里的）
答：……
### 单元小测 / 课后巩固（素材里有就放）
# 参考答案
```

要点：知识点按教材课时顺序；历史类可加「时间｜事件｜意义」三栏写法（用 `!时间：` 这类小标签逐条写，不用表格）；背诵类重点词全部 `{{}}`，背诵默写版就是主产品。

### 二之一、英语语法手册（知识清单 + 分层练习）

规模参考：一册 8 章、13–21 个语法点、约 380 题，正文 100–120 页 + 封面。
素材典型组合：电子课本（看 Grammar Focus 页，书后 Grammar 附录是讲解的第一出处）+ 每单元两三份解析版 Word（专讲、巩固练习、精讲精练），讲解和题都从里面取，取题流程见取题流程.md。有课文语法填空素材时，提升练习每章末尾放一篇（cloze）。

```
文件头 类型: 知识清单 / 学科: 英语
# Unit 1 You and Me                      ← 教材单元一章；Starter 单独成章
> Grammar：……〔S01 p6〕                   ← 课本目录页的 Grammar 名称
## 语法 6：be 动词 am / is / are〔S04 A（一）；S05 讲解；S01 p32〕   ← 全书连续编号
【课本原句】  | 课本 Grammar Focus 的完整句子，来源行 ——《Unit 1 Grammar Focus》（填空题不收）
【口诀】      素材有才放
【知识点】    #### 1. 小标题（一条规则一个）→ 规则一两句 → - 例句｜译文 → 能列表的用 [表]
【易错点】    !小标签：内容〔出处〕；可带一条 - 例句
【拓展】      超出本册的用法（表推测、过去式、分数、双重所有格……），放在语法点最后
例：……（　　）〔素材题号〕 / A．…｜B．… / 答：C　一两句理由（取素材解析）
## 语法 7 ……
[分页]
### Unit 1 基础练习        ← 刷语法类素材的单选为主，约 20–25 题
### Unit 1 提升练习        ← 精练类素材：单选 + 词形填空 + 句型转换 + 连词成句 + 翻译，约 20–25 题
[答案] Unit 1 参考答案     ← 本章答案另起一页，按基础 / 提升分组，答案 + 素材原解析
# Unit 2 ……
```

规矩：
- 知识点、易错点要全面丰富：课本和每份素材里出现过的规则、例外、易错提醒、口诀都收，宁多勿漏；但每句都要能对回素材
- 超纲内容放【拓展】，练习只选本册范围内的题
- 例题、易错点引用过的题不再进练习；同一道题在两份素材或两章里出现只收一次
- 讲细讲全，别写得单薄：把每道题【详解】里的规则逐条收进讲解（素材的讲解部分往往只占一小半，规则大多藏在解析里），再翻课本 Section A/B 找原句；每个语法点加【考点】，归纳这一章的题怎么考
- 【考点】和讲解只讲规则，不写出练习里某道题的答案；讲解要引用的题，先从练习里撤掉
- 素材说法互相矛盾、或和课本矛盾时，以课本为准；拿不准的只写双方都认的部分，覆盖表里写明
- 一般现在时这类跨单元的语法只在第一次出现的章讲，后面写「见 Unit 2 语法 8」
- 第一章就是样章（确认点二），定了再一章一章铺开；每章做完先自查，中间不再停
- 答案默认保留素材全文解析（篇幅约占全书 40%），要不要精简问用户

篇幅参考：每个语法点讲解 1–2 页，每章练习 3–5 页，答案 3–5 页。

### 二之二、中考语法总复习（没有教材，按语法体系排）

规模参考：三篇（词法 / 动词 / 句法）22 专题 81 考点 + 附录，约 950 题，约 300 页。
- 章 = 专题（`# 专题 N　名词`），篇首页写成 `# 第一篇　词法` + 一行说明，放在该篇第一章讲解文件开头
- 每章开头 `> 中考怎么考：……`（讲义「命题预测」+ 课件「考查方向」），代替【课本原句】
- 考点用 `## 考点 N`（全书连续编号），所以「中考怎么考」那一栏改叫【考法】、条目写 `!考法 N`，避免和 ## 考点 重名；多一栏【解题技巧】
- 练习三组：基础（考点通关）≤ 25、提升（真题实战，保留（2025·地区））≤ 25、语篇 1 篇；只有提升练习的章在 json 第一组加 `"break": true` 另起页
- 内容稿文件头加 `答案排法: 紧凑`：答案和解析排在同一段，答案区省约三分之一篇幅（每章约 13–14 页）

## 三、专项题库 / 专项训练

适合：计算题专项、应用题专项、句子专项、语法 3000 题、阅读 40 篇 + 完形 10 篇这类按题型归类的练习。

```
# 题型一：……（按题型分，不按单元）
> 这一类题考什么（素材原话）
## 方法：……                         ← 素材有解题方法时才有讲解区
【答题思路】【答题模板】例：答：
### 基础练习 / ### 提升练习          ← 分层，篇目或题组
1.2.3. 题目，选项，[横线]
# 参考答案
## 题型一
### 基础练习
1.参考答案：…… （素材有解析才写「详细答题思路」）
```

要点：题号在每个题组内从 1 开始；答案条数必须和题数一致（check 会核对）；素材只有答案没有解析时，不补解析。

## 四、试卷

适合：单元测试卷、期中期末模拟卷、真题卷整理。

```
[卷头] 2026 秋三年级语文期中测试卷
### 第一部分 积累与运用（30 分）       ← 试卷结构用练习区标记
一、看拼音写词语。（8 分）
1.……
### 第二部分 阅读（30 分）
| 短文
一、……
# 参考答案
## 期中测试卷
### 第一部分 积累与运用
1.参考答案：……
```

要点：一套卷一个项目，多套卷用 `# 第一套 / # 第二套` 分；卷面不用彩色讲解栏目，保持黑白为主（卷头、大题、题目、横线）；答案另起一页，可只出「练习题 + 参考答案」两个版本。

## 五、背诵默写

不单独做框架，从前四类自动拆出（`背诵默写` 版本）：
- 第 1 页打卡表：每个考点 / 知识点一行，「完成 √ ×」「家长签字」两栏
- 前半本背诵版：讲解区全部内容，`{{关键词}}` 加下划线
- 后半本默写版：同样内容，关键词挖空，答题模板整句换成横线

所以写内容稿时就要想好哪些词该背：答题思路里的方法名、模板里的固定说法、知识点里的核心术语，每个考点 3–8 个。
