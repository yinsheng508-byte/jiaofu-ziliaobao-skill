# 经典版式规范（考点答题模板、英语语法手册共用的 build_docx 引擎）

Word 版（含 PDF）怎么排。通用视觉要求见 references/视觉规范.md；手写笔记版见 templates/手写笔记/。

参照品：一份市售的《三上语文阅读理解考点与答题模板》完整版（WPS 文字导出，A4，100 页），颜色由 PDF 实测取色。
所有数值都在 `<skill>/config/排版参数.json`，`build_docx.py` 把它们写成 Word 样式（样式名「资料-××」，单元条用「标题 1」、考点用「标题 2」，Word 导航窗格能看到）。
**改排版改排版参数.json，不在内容稿里手动加格式；用户在 Word 里改样式也能全书生效。**

## 一、总原则：要人味，不要机械感

一定要先用 Word 一页一页精细化排版，再转 PDF。直接用代码排 PDF 出来是机械感，我们要的是人味。人味来自这几件事：
1. **一色一义**：每种颜色只表示一件事，全书不混用。家长扫一眼就知道哪是问法、哪是模板
2. **讲和练分得开**：讲解区整段加粗、宋体四号；练习区不加粗、楷体小四。一翻就知道哪里在讲、哪里要做
3. **密度高但不挤**：页边距窄、行距固定，一页装得下一个完整考点；栏目之间不空行，靠彩色标签分隔
4. **像老师排的**：作答横线按答案长短给、来源右对齐、题后标分值、选择题括号在句末——这些细节机器排版不会做
5. **分页有讲究**：考点标签不落在页尾、短文和题尽量同页、单元和答案另起一页

## 五、细节规矩

- **画线句**用单下划线；**加点字**用着重号（字下加点），不要用加粗或换色代替
- **分值**写在题末「（2 分）」；选择题括号「（　　）」放句末，里面两个全角空格
- **填空横线**：句中填空用「＿＿＿＿」（全角下划线，长度按答案字数，约每字 2 个）；整行作答用 `[横线N]`
- **标点**：中文全角；英语学科的英文句子用半角；中文引号「“”」紧贴文字，前后不留空格
- **序号**：讲解区「1.」「2.」或「①」「②」；练习大题「一、」，小题「1.」，小小题「（1）」
- **答题模板里的占位**：人名事物用「××」，句子成分用「……」，可选词放全角括号里用「/」隔开
- **加粗**：只在样式层面加（讲解区整段加粗）；不在句子中间零星加粗强调

## 六、精排检查清单（每次 build 后逐页过）

用 Read 看 `2_样张/预览/<文件名>/总览-*.png`，有疑问的页看单页 `p-NN.png`（需要看清字时 `$RUN render <项目> --pages N --dpi 120`）。

| # | 检查项 | 不过怎么改 |
|---|---|---|
| 1 | 第 1 页目录页码齐全、和正文对得上 | build 会自动回填；仍有空缺看终端「目录没找到页码」提示，多半是标题里有特殊字符 |
| 2 | 考点标签、栏目标签没有落在页尾（下面内容在下一页） | 样式已设「与下段同页」；仍出现就在考点前加 `[分页]` |
| 3 | 例文和它的题、示范答案在同一页，或者至少题目和答案不分家 | 例题前加 `[分页]` |
| 4 | 练习短文和第一道题之间不断页；跨页时从题目之间断 | 练习标题前加 `[分页]` |
| 5 | 没有孤行：页首页尾只剩一行 | 前面合并短段、减一条横线，或加 `[分页]` |
| 6 | 页尾空白不超过 1/3 页（单元末页、答案前一页除外） | 把下一个短块挪上来，或去掉不必要的 `[分页]` |
| 7 | 选项排列整齐，没有一个选项折成两行 | 选项写成两行，或「｜」分组 |
| 8 | 作答横线长短合适 | 改 `[横线N]` |
| 9 | 黄框、标签底色只包文字，没有通栏 | 不应出现；出现说明样式被改，查排版参数.json |
| 10 | 颜色用对：紫问法、绿思路、红模板、蓝答案 | 内容稿栏目标签写错，改标签 |
| 11 | 没有红字【缺】（成品） | 补内容或删块 |
| 12 | 页脚「第 X 页 共 Y 页」正确 | — |
| 13 | 没有孤页：练习、答案前一页只剩一两题或两三行 | `$RUN qa pages` 列出来；回收办法按顺序试：短问答 `join` 成一行 → 例题的「答：」精简成一行（意思不变）→ 最后才动行距；**不删题**，也不为一处孤页改全书行距（会把孤页挪到别处） |
| 14 | 目录页码和页脚一致（加了封面也一致） | `$RUN qa pages` 逐条核；不对的多半是标题重名或带特殊字符 |

## 七、PDF 导出

- **成品 PDF 用 Word 导出**（`--engine word`）或用户在 Word/WPS 里「文件 → 另存为 → PDF」。Word 导出的和用户在 Word 里看到的一致
- 默认引擎：Mac 是 LibreOffice（`lo`），只当预览和目录页码定位；Windows 装了 Word 时直接用 Word
- LibreOffice 读不到 macOS 系统中文字体，脚本会把排版参数.json的字体文件复制进独立配置目录
- Word 导出时会再按 Word 的 PDF 回填一次目录页码（Word 和 LibreOffice 分页常差一页）
- 正式 PDF 在哪台电脑导出，就在哪台电脑 build：Mac 上生成的 .docx 拿到 Windows 打开，宋体会被替换，分页可能变
- 用户在 Word 里手动精排过的 .docx 不能再 build（会被覆盖），只能 `$RUN pdf <项目>` 重新导出
- 不用 reportlab、HTML 转 PDF 之类的方式直接排 PDF

## 九、知识清单主题（初中及以上语法 / 知识点手册）

小学参照品那种整段四号加粗的讲解区，放到知识点、例句、缩写很多的初中资料上会糊成一块，所以知识清单换一套更清爽的主题。
内容稿写 `类型: 知识清单` 时自动套 `排版参数.json` 的 `themes.知识清单`，其他类型不受影响。

| 元素 | 样式 |
|---|---|
| 语法点（`##`） | 14 pt 主题蓝 `#1F4E79` 加粗，通栏浅蓝底 `#DEEAF6` + 左侧粗色条 + 下边线 |
| 知识小标题（`####`） | 12 pt 主题蓝加粗，单倍行距，**不加左侧竖条**（竖条怎么调都和字不协调） |
| 讲解正文 | 11.5 pt **常规字重**，行距 20；只有 `{{关键词}}` 加粗主题蓝 |
| 例句（`- `） | 11 pt，缩进 0.75 cm，▸ 引导；中文译文灰 `#7F7F7F` 小一号 |
| 表格（`[表]`） | 10 pt，表头浅蓝底主题蓝字，细框线 `#9DB7D5`，单元格上下留白收紧，短列居中；≤5 行整表不跨页，>5 行长表允许行间自然跨页并自动重复表头（避免半页大空白）；表后只留 3 pt 小空 |
| 课本原句 | 浅绿底 `#EEF6E8` + 左绿条，来源灰色右对齐 |
| 口诀 | 浅橙底 `#FFF4D6` + 橙框，12 pt 红字加粗 |
| 易错点 | 红色加粗小标签 + 常规正文，段后 3 pt |
| 例题 / 答 | 选项另起一行四栏；「答：」后答案蓝色加粗下划线，解释常规黑字 |
| 练习标题（`###`） | 13 pt 主题蓝加粗居中，浅蓝底 + 上下细线 |
| 章内答案标题（`[答案]`） | 和练习标题同样式，另起一页；答案里按「基础练习 / 提升练习」分组 |
| 练习小题 / 选项 | 12 pt，行距 20 |
| 答案题 / 答案行 | 12 pt，行距 19 |
| 练习大题 | 12 pt 主题蓝加粗 |

逐页检查时，知识清单额外看：表格有没有被拆到两页、例句有没有和规则挤在一段、一页里有没有连续三段以上纯文字（能拆表的拆表）。

## 十、封面

要「真实书皮的感觉」，简单干净。色块 + 气泡 + 数据卡片 + 表格堆在一起的封面会显得花、粗糙。
样板在本模板的 `封面样板/`：`封面_C酒红（推荐）.html` 是字母版，`封面_A深蓝.html` 线稿版、`封面_B墨绿.html` 米黄版可参考。复制一份到 `<项目>/封面/封面.html` 再改。字体写法照样板：每个中文字体后面都跟上 Windows 的替补（微软雅黑、宋体），Mac、Windows 出来一样。

| 项 | 做法 |
|---|---|
| 底 | 浅色纸面（白 / 米黄 / 浅灰蓝），叠一层很淡的纸纹 |
| 书脊 | 左侧 17 mm 深色布纹色带 + 一道折痕阴影，颜色就是全封面唯一的主色 |
| 书名 | 方正大标宋（`FZDaBiaoSong-B06`）大字，两行，主色或近黑；上面一行年级册次，下面一行副名（与分层练习） |
| 分隔 | 细线（0.35 mm，主色的淡色），不用色块 |
| 英语感 | 一行衬线斜体英文（English Grammar Handbook · Grade 7），装饰用超大淡色衬线字母「Aa」或淡色线稿（作业纸、钢笔），二选一 |
| 卖点 | 左下角细线隔开的 3–4 条，斜体编号 01 02…，粗体短标题 + 小字说明；最下一行「Starter – Unit 7 · 8 单元 · 21 个语法点 · 376 道练习」 |
| 不要 | 气泡、彩色数据卡片、多种主色、渐变色块；编造的出版社、书号、价格、名师推荐、「全解全析」这类说不实的词 |

做法：`2_样张/封面/封面.html` 写成 A4 单页（`@page size 210mm 297mm; margin 0`），build 完整版时 `scripts/cover.py` 用 Chrome 无界面导出，拼到 PDF 最前面，并把页码标签设成「封面、1、2…」，用预览 / WPS / Adobe 看时阅读器页码和目录、页脚一致（浏览器不认页码标签，会多 1）。
给用户挑方向时，同一版式出 2–3 种配色 / 装饰，拼一张并排图让用户选。
