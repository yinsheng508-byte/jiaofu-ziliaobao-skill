# /商品主图

「教辅资料包」skill 的商品主图分支入口。

- `<skill>` = `<SKILL_DIR>`（`run.py setup` 安装时换成本机的实际路径；还是尖括号占位符说明没装好，让用户重跑 setup）
- 命令：`python3 <skill>/scripts/run.py mainimg ...`（Windows 用 `python`），下文记作 `$RUN mainimg`

**动手前读** `<skill>/templates/商品主图/模板说明.md`（做法全文），写 spec 时读同目录的 `spec格式.md`，挖卖点读 `卖点挖掘.md`。

## 必守

1. **店铺名必须由用户这次提供**：没给就只问一句「店铺名称写什么？」；不猜、不沿用别的项目，不写进 skill、模板、偏好
2. **固定 3 张**：01 商品主图 → 02 购前须知 → 03 卖点展示
3. **主图里的资料页只用我们自己的成品**（资料包项目的 `3_成品/`，已过交付检查）；不放原素材页面、不放同行截图
4. **不编造**页数、版本、销量、名师；不用极限词（最、第一、100%、保过、官方……）；拿不准的列进《卖点说明.md》「待确认」
5. 版式照模板，不描边、不投影、不渐变，全图四类颜色

## 流程

1. 输入：资料包项目 → 输出到 `<项目>/3_成品/主图/`；只给主题 → `输出项目/<日期>_<产品主题>_主图/`
2. 资料页：`$RUN mainimg pages <资料.pdf> <输出目录>/assets 6`
3. 挖卖点（卖点挖掘.md），选主图模板（`$RUN mainimg templates`）
4. 写 `spec.json`（spec格式.md），`$RUN mainimg <输出目录>/spec.json`
5. 逐张看图自检（模板说明第七节），最多改 2 轮
6. 写《卖点说明.md》，把 01–03.png 发给用户，列出待确认事项
