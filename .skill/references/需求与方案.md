## 一、需求单（第 ① 步照填）

开工先在项目里写《需求单.md》。用户已经说了的直接填；没说的按第四节问；偏好文件（`run.py prefs`）里有的默认值先填上，标「默认」。

```
# 需求单
资料名称（暂定）：
给谁用：（第三节的用户群）
用来做什么：同步预习 / 期末复习 / 背诵默写 / 刷题 / 考前冲刺 / 打印做笔记 / 发小红书 / ……
学科、年级或考试、教材版本：
教材课本（1_教材课本/）：版本、有没有（没有就按取材规范第四节处理）
对标资料（2_对标资料/）：同行成品、讲义、真题、用户自己整理的资料
参考版式（3_参考版式/）：想要的排版样子（没有写「无」，方案阶段从主题库挑）
上传：做完要不要传飞书知识库 / ima 知识库（可选）
交付形式：Word + PDF / 手写风 PDF + 图片 / 小红书图
版本：例：背诵版 + 默写版；完整版 + 答案分册；只要一本（由用户定，不默认 5 个版本）
改写档位：整合升级（默认，做成 AI 原创资料产品） / 轻整理 / 只排版
篇幅：页数，或「全册」「第几到第几单元」
```

**完成标准**：给谁用、做什么用、交付形式、改写档位四项都有确定答案。

## 二、拆解用户给的参考

用户发了参考，就逐项拆，写进需求单的「参考拆解」一节。**参考是第一标准**，和规范、画像冲突时照参考，冲突点写进方案请用户确认。

| 拆什么 | 例 |
|---|---|
| 分几册 / 几个版本 | 背诵版 + 默写版；题目版 + 答案版 |
| 章节结构 | 章 → 节 → 考点；单元 → 课 → 知识点 |
| 每个单元有哪些栏目 | 考情表、考点、点拨、口诀、例题、练习、答案 |
| 内容密度 | 一页大约几个知识点、表格多还是文字多 |
| 版式 | 主色、字体、标题样式、重点怎么标、表格样式、页眉页脚（对照视觉规范第七节的四种风格） |
| 卖点 | 「真题出处」「考频标注」「一页一考点」…… |
| 不学的地方 | 参考里的店铺名、水印、账号这些原作者信息一律不学 |

参考是截图时，用 Read 逐张看图，拆完把截图存进 `1_规划/参考/`。

## 四、必须问 / 不该问 / 怎么问

### 必须问（命中就停下来问）

| 情况 | 问法示例 |
|---|---|
| 需求单里给谁用、做什么用、交付形式、改写档位任一项不知道 | 「这份是给学生自己背，还是老师发给家长？」 |
| 参考和用户说法矛盾 | 参考有练习题，用户说只要知识点 |
| 教材版本对不上 | 「素材是 2019 版，课本是 2024 版，以新课本为准可以吗？」 |
| 素材缺整章、整单元 | 「第五单元没有素材，补素材还是先不做这单元？」 |
| 素材之间说法矛盾，课本也没写 | — |
| 方案页数超出预期一倍以上 | — |
| 内容疑似有版权风险（出版社电子书、大机构课程原文） | — |
| 用户的要求会违反红线（让编题、让留原作者名） | 说明原因，给替代办法 |

### 不该问

- 规范里已经有答案的（字体、颜色、出处怎么标、分页）
- 用户开工时说过的、需求单和进度记录里有的
- 单个错别字、格式问题、哪道题放前面
- 没有具体选项的「这样可以吗？」

### 怎么问

- 一次攒齐，**最多 3 个问题**，每个给 2–3 个选项和各自效果，标出推荐项
- 写清「不回答的话我按 X 做」
- 用 AskUserQuestion 时一次调用问完
- **用户不在线**（自动运行、验收）：不等回答，把问题和推荐选项写进 `1_规划/提问记录.md`，按推荐选项继续，确认点照样停下汇报

## 五、方案模板（确认点一）

写《方案.md》，**照这个结构填，不增不减**：

```
# 方案：<资料名称>

## 需求摘要
给谁用 / 做什么用 / 交付形式 / 版本 / 改写档位（各一行）

## 参考拆解
（第二节的要点，3–6 行）

## 目录
| 章 / 单元 | 节 / 考点 / 篇目 | 用哪些素材 | 预计页数 | 备注 |
|---|---|---|---|---|
| 第一章 …… | 第一节 …… | S01 p2–5、课本 p3 | 3 | S01 最全，做主体 |
| | 练习：【缺】第 5 篇 | — | — | 素材只有 4 篇 |
合计约 N 页

## 版式方向
风格（视觉规范第七节四选一或照参考）、主题（assets/主题/ 里选）、主色、字体、每章结构、页眉页脚、封面要不要
套用模板：templates/<模板名>（没有相近的写「新建」）

## 缺口
【缺】……（没有写「无」）

## 原作者信息
入库扫出的名字、店铺、品牌（会全部去掉）：……

## 待你定的事（≤3 个，带选项）
1. ……　A. ……（推荐）　B. ……
```

**完成标准**：每一章、每一节都写了用哪份素材；版式方向写到具体主题；待定的事带选项。

## 六、三个确认点和进度记录

| 确认点 | 交给用户什么 | 用户确认后 |
|---|---|---|
| 一、方案 | 《素材覆盖表》《方案》的完整路径 | 搭工具、写第一章 |
| 二、第一章样章 | `2_样张/样章/` 里的第一章成品 PDF + 2–4 张预览图 + `2_样张/样章汇报.md`（第七节）。样章 = 第一章；整本只有一两章时，样章 = 第一课或第一节，方案里写明 | 调整写进「样章定稿标准」，其余章节照做，**中间不再停** |
| 三、交付 | `3_成品/` 里的全部成品 + 交付汇报（质检与交付第五节） | 按意见返修 |

- 只有会推翻方案的大问题才中途额外停：缺整章素材、页数超一倍、教材版本对不上
- 用户说「不用看样章」就跳过确认点二，写进进度记录
- 《进度记录.md》（`run.py new` 自动生成）每做完一步就更新：需求单摘要、用户已定的事、确认点状态、样章定稿标准、每章状态和闸门结果、下一步。**换会话后第一件事读它**

```

- 文件：<PDF 完整路径>；预览：<2–4 张图>
- 收了哪些内容：……（来自 S01、S03、课本）
- 原样保留的：……；重新组织的：……
- 版式上的选择：主题 ×××，重点用 ×××，每节 ×××
- 闸门：出处 ✅ 机器味 ✅ 原作者信息 ✅ 填充率 ✅（最低一页 N%）
- 想请你看的地方：（≤3 个，带选项）
```
