# spec.json 格式

完整示例：`templates/商品主图/示例/spec-example.json`。图片路径可写相对 spec.json 的路径。

```jsonc
{
  "模板": "经典蓝框红字",                  // 可选，assets/主图模板/ 里的模板名（run.py mainimg templates 看有哪些）
  "shop": "用户给的店铺名",               // 必填，每次由用户提供，不写进 skill、模板、偏好
  "theme": {"blue": "#2152C6"},           // 可选，在模板基础上再覆盖配色：blue/blue_dark/blue_light/red/kicker/panel/paper/ink
  "footer": {                             // 所有页共用的底部条，单页可用 pages[i].footer 覆盖，写 false 去掉底部条
    "small": "24小时自动发货", "big": "百度网盘",
    "ribbon": "答案版 | 空白版 | 可打印", "pill": "2026秋季新版"
  },
  "pages": [
    {
      "type": "cover",
      "kicker": "初中全科",                 // 可选，深色小字
      "title": ["七年级", "上册"],          // 红色大标题，1–3 行，自动按宽度缩放
      "selling": ["紧扣[[新教材]]同步编排", "知识点+练习{{一套搞定}}", "答案版 / 空白版都有"],  // 3 条卖点，不写注意事项
      "subjects": ["历史","地理","道法","生物"],  // 可选，合集类商品的科目/分册方块，填在标题和卖点之间（2–6 个）
      "tag": "笔记同款",                    // 产品卡顶部胶囊，"" 则不显示
      "card_note": "背诵版+默写版 各{{39}}页",  // 可选，资料卡下方一行（页数/份数等真实数据）
      "product": {
        "image": "assets/page-1.png",       // 一页真实资料，按原比例显示，不拉伸不裁切
        "cover": {                          // 无图时生成仿资料封面
          "top": "— 七年级上册 —", "title": ["七年级上册", "资料合集"],
          "sub": "—知识梳理与练习—", "items": ["语文 · 数学 · 英语"]  // items 可选，最多 4 行
        }
      }
    },
    {
      "type": "notice",                     // 第 2 张：购前须知，默认不带底部条
      "heading": "购前须知",
      "sections": [                         // 可省略，省略=内置默认文案（百度网盘）
        {"title": "关于商品", "body": "商品为{{电子版文件}}，无实物，无快递。"},
        {"title": "如何获取", "body": ["第一步……", "第二步……"]}  // 列表=自动编号 1. 2.
      ]
    },
    {
      "type": "points",
      "heading": "为什么选这份？", "sub": "开学预习 · 期末复习都能用",
      "images": ["assets/page-2.png"],      // 可选，0–3 张内页图（按原比例，自动留够卖点卡高度）
      "captions": ["背诵版"],               // 可选，图片顶部红色角标，与 images 一一对应
      "image_h": 420,                       // 可选，图片行最大高度
      "points": [{"title": "紧扣[[新教材]]同步编排", "desc": "按单元顺序整理"}]  // 3–4 条；有 images 时 3 条
    },
    {
      "type": "grid",
      "heading": "资料内容一览", "sub": "一次下单 · 全科打包",
      "cols": 2,                            // 2 或 3
      "items": [{"name": "语文", "desc": "字词积累 · 古诗文默写"}],  // 也可直接写字符串；文案里写 \n 换行
      "note": "下单后自动发货，链接永久有效"   // 可选，底部一句话
    }
  ]
}
```
