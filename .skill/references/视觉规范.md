## 一、核心：真实的 Word 精排，不要机器感

成品要像一个老师在 Word 里一页一页调出来的：**用 Word 自带的样式、自动目录、真表格、制表位、页眉页脚、突出显示**，打开 .docx 每个元素都能直接改。
不做成「网页截图 / 卡片海报」，不用代码直接排 PDF。**手写风笔记是唯一例外**（走 `templates/手写笔记`）。

## 二、好看的 7 条标准（逐条可查）

| 标准 | 要求 |
|---|---|
| 层级一眼清楚 | 标题最多 4 级，每级字号、颜色、字重至少一项不同；同级全书同样式 |
| 有重点 | 第五节的三层重点；一页红字加粗 ≤8 处，不满屏标红 |
| 图表化 | 能对比的做表，能分类的做导图或括号树，有图的配图；**连续 3 段以上纯文字要拆** |
| 统一 | 全书一套主题：颜色 ≤5 种、字体 ≤3 种、每种组件一种样式；封面、目录、内页同一风格 |
| 饱满 | 内容丰富；正文页填充率 ≥80%（章末页不限） |
| 精致 | 对齐、缩进、间距、线条粗细统一；没有挤在一起或飘出去的东西 |
| 真实 | 像人工精排的实体资料（第一节），没有第九节的禁区 |

## 三、版式系统（方案里定，写进项目 `2_样张/排版/样式.json`）

| 项 | 规则 |
|---|---|
| 主题 | 从 `assets/主题/` 选一套（第七节），或照参考新建一套存进去 |
| 颜色 | 全书 ≤5 种（不算黑白、图片里的颜色）：一般 1 主色 + 1 强调红 + 灰 + 1–2 种浅底色；不随手写色值，都从主题取 |
| 字体 | ≤3 种：正文宋体，标题黑体 / 粗宋 / 方正大标宋，英文数字 Times New Roman；注释、点拨可以用楷体 |
| 字号 | A4 正文 10.5–12pt；标题按级递增；同级同字号 |
| 行距、段距 | 固定值或倍数，全书统一（密的 1.0–1.15，松的 1.25–1.5）；段后留小间距 |
| 页面 | A4；页边距统一（一般上下 1.8–2.5cm、左右 1.6–2.5cm） |

## 四、Word 元素怎么做

| 元素 | 做法 |
|---|---|
| 目录 | Word 目录：一级加粗、页码加粗；二级缩进，可以用主色、带 01 / 02 编号；**点线前导符连到右对齐页码**；章之间空一行；「目　录」居中 |
| 标题 | Word 标题样式（导航窗格看得到）：章标题居中大号加粗，下面可以一条主色细线；节标题加粗，左侧可加主色竖条或编号 |
| 页眉页脚 | 页眉：系列名或书名，下面细线或粗细双线；页脚居中「第 X 页 / 共 Y 页」；章首页可以不要页眉 |
| 正文 | 宋体；编号段落用悬挂缩进，换行后和上一行文字对齐 |
| 表格 | **真表格**：撑满版心宽度；表头浅底纹加粗居中；首列加粗或浅底；框线细、颜色统一（或三线表）；短内容居中、长内容左对齐；表头跨页重复；≤5 行的表不拆页 |
| 标签 | 「考点 1」、【全背】【25 下选择】、「25-26 福建漳州·期中改编」这类**真实信息**放在标题或题号后；一类标签一种样式；不拿标签当装饰 |
| 提示框 | 点拨、口诀、易错：浅底色 + 细框或虚线框，框里字小一号；一页 ≤2 个 |
| 图 | 放在讲它的文字旁边，用文字环绕（四周型 / 上下型）；配图注 |
| 题目 | 大题加粗「一、……（每题 2 分，共 10 分）」；**选项用制表位对齐成 2 栏或 4 栏**，不用空格凑；作答空用下划线或括号，长度按答案 |
| 答案 | 答案红色；解析前加【解析】这类标签；解析用「考查……，故答案为 B」的老师口吻 |

## 五、重点和颜色

三层重点，按层级用，**黑色正文占大部分**：

1. 关键词：红字加粗（要挖空的加下划线）
2. 要整句记的：浅黄或浅粉突出显示 + 红字加粗
3. 补充说明：蓝色（可以楷体、加括号）

- **关键词、条目标签、表格首列的加粗必须保留**；「调轻」只动底色、线条、标题装饰，不动加粗
- 一色一义：每种颜色只表示一种意思，全书不混用

## 六、排满与分页

- 填充率：正文页 ≥80%；章末页（下一页是新的章或节）、章首页、封面、目录不限。`gates` 自动报
- 填不满就补素材里的细节（内容规范第三节），**不放大字号、不加装饰凑**；也不缩字号、压行距硬塞
- 章（一级标题）另起一页
- 标题不落页尾；例题和答案、图和说明、表和表题不分家
- 没有孤页：练习、答案前一页只剩一两行的，用合并短行、精简答句回收

## 七、四种参考风格和主题库

| 风格 | 适合 | 特征 |
|---|---|---|
| 笔记讲解风 | 面试、方法论、大学课程、求职 | 短段落；节标题左侧色条 + 编号；重点句黄底红字 |
| 考点表格风 | 教资、考公、考研、高中专题 | 章首考情表；「考点 N」标签 + 考频；表格为主体；关键词浅粉底；点拨框 |
| 知识点汇总风 | 小学、初中同步知识点 | 彩色分段大标题；单元标题黄底；编号条目；关键词红字下划线；表格首列浅底；配图环绕 |
| 标准试卷风 | 单元卷、期中期末卷、真题汇编 | 黑白为主；卷头 + 得分表；大题加粗带分值；选项制表位对齐；答案卷红色答案 + 解析 |

| 风格 | 现成的模板 |
|---|---|
| 知识点汇总风 | `templates/知识手册_背诵默写`（主题选学科色或「知识点汇总风」） |
| 考点表格风 | `templates/考点表格_背诵默写` |
| 标准试卷风 | `templates/考点答题模板`（经典引擎的试卷类型），或新建 |
| 笔记讲解风 | 还没有，第一次做时照模板指南新建，做完沉淀 |

`assets/主题/` 里每套主题有颜色、字体、组件样式，学科色有效果图（`$RUN theme list`）。方案阶段先挑主题；参考里的风格主题库没有，就照参考新建一套，项目做完存进主题库。

## 八、封面和目录

- 封面像真实书皮：书名、适用年级 / 考试、版本说明、3–4 条真实卖点；不编出版社、书号、价格、推荐语；**不出现原作者名、店铺名、系列品牌**
- 目录页码和正文、页脚一致（`gates` 核）

## 九、机器感 / AI 味禁区（出现就改）

- 网页 / 海报感：圆角卡片、投影、满版色块背景、渐变、emoji 和图标堆砌、同样大小的卡片平铺满页
- 导出痕迹：目录没页码或对不上、标题不是 Word 样式、表格是图片、选项用空格硬对齐、全文一种字号
- 颜色失控：正文大段彩色、一页超过 3 种高亮色、每种框一个颜色
- 装饰过度：白字色块小标签堆叠、英文小标题（UNIT 01、CONTENTS）、双线粗横条满页、◆●★ 满天飞
- 太空太素：段距、页边距过大像 PPT；或完全没有层次，像 Word 默认样式

## 十、跨系统

- Mac 和 Windows 字体自动对应（Songti SC ↔ SimSun，Kaiti SC ↔ KaiTi，Heiti SC ↔ SimHei）
- 正式 PDF 在哪台电脑 build 就在哪台导出；优先用 Word 导出
