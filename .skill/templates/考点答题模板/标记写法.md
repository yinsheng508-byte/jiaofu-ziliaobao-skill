# 内容稿标记（内容稿.md 怎么写）

内容稿是**纯文字 + 少量标记**。只管内容和结构，颜色、字号、行距、分页全部由 `build_docx.py` 按 `排版参数.json` 套 Word 样式。
写内容稿时不要自己加颜色、不要用 Markdown 粗体/表格，用下面这些标记。

目录
- 文件头
- 结构标记（行首）
- 讲解区（考点下面）
- 知识清单专用（`类型: 知识清单`）
- 练习区（`###` 下面）
- 答案区（`# 参考答案` 之后，或章内 `[答案]` 之后）
- 行内标记
- 卷面专用（类型: 试卷）
- 最小示例
- 考点 12：结合文章内容评价童话人物

## 文件头

```
---
标题: 26秋新版三上|blue 语文|black 阅读理解考点|red 与|black 答题模板|green
副标题: 配套练习题含答案
简称: 三上语文阅读理解考点与答题模板
类型: 答题模板
学科: 语文
目录篇目: 是
---
```

- `标题`：彩色拼接标题，空格分段，每段「文字|颜色」，颜色取 blue / black / red / green / purple
- `简称`：成品文件名用
- `类型`：答题模板 / 知识清单 / 专项题库 / 试卷（见本文件夹的 资料框架.md）
- `学科`：语文 / 数学 / 英语……；数学的算式公式不按「等号」机器腔查
- `目录篇目`：目录里是否列出练习篇目（三级），默认是
- `答案排法: 紧凑`（可选）：参考答案区「n.参考答案：X」和下一行「解析：……」排成一段（显示为「n.X　解析：……」），答案区省约三分之一篇幅；适合答案多的语法书

## 结构标记（行首）

| 写法 | 生成 | 说明 |
|---|---|---|
| `# 第一单元（校园生活）` | 单元条（浅橙粉底通栏，另起一页） | `# 参考答案` 开始书末答案区；章内答案用 `[答案]`（见答案区） |
| `> 阅读时，关注有新鲜感的词语和句子` | 单元要素（红字居中） | 紧跟在 `#` 后面 |
| `## 考点 1：找出具有新鲜感的词语或句子` | 考点（黄底黑框） | 答案区里 `## 第一单元` 是答案单元小标题 |
| `### 乡村小学（节选）` | 练习标题（居中加粗），之后进入练习区 | 答案区里是答案篇名 |
| `[分页]` | 强制分页 | 精排时用 |

## 讲解区（考点下面）

| 写法 | 生成 |
|---|---|
| `【常见问法】` | 浅绿底标签；后面的行用紫色加粗 |
| `【答题思路】` | 浅粉底标签；后面的行用绿色加粗 |
| `【答题模板】` | 浅紫底标签；后面的行用红色加粗 |
| `【解析】` `【知识点】` `【易错点】` `【方法】` | 其他标签，见 经典版式规范.md 表 |
| `!有动态感的词语：飘扬、摔跤、看热闹` | 第一个冒号前红色加粗做小标签，冒号后跟随当前栏目颜色 |
| 其他普通行 | 跟随当前栏目颜色 |
| `例：找出你觉得具有新鲜感的词语和句子。` | 例题（黑色常规） |
| `\| 早晨，从山坡上……` | 例文（楷体，首行缩进 2 字）；一行一段 |
| `——《大青树下的小学》` | 来源（楷体右对齐） |
| `答：词语：绒球花、穿戴、绚丽多彩、飘扬。` | 「答：」黑色，后面蓝色加粗下划线 |

## 知识清单专用（`类型: 知识清单`）

| 写法 | 生成 |
|---|---|
| `#### 1. 否定句：在 be 动词后直接加 {{not}}` | 知识小标题（主题蓝加粗）；一条规则一个小标题 |
| `- I am not a boy.｜我不是男孩。` | 例句：▸ 开头，英文常规黑字，「｜」后中文灰色小一号 |
| `[表]` … `[/表]` | 表格：一行一排，格子用 `\|` 分；第一行是表头（浅蓝底）。`[表 无表头]` 不要表头，`[表 首列]` 首列加粗；短内容自动居中，整表不跨页 |
| `【课本原句】` 下的 `\| 句子` | 课本引用块（浅绿底、左绿条），来源行写 `——《Unit 1 Grammar Focus》` |
| `【口诀】` 下的行 | 口诀框（浅橙底、红字加粗） |
| `【易错点】` 下的 `!小标签：内容` | 红色加粗小标签 + 常规正文，条与条之间留空 |
| `【拓展】` | 超出教材的内容单独放这一栏，放在语法点最后 |
| `【考点】` 下的 `!考点 N　标签：内容` | 中考怎么考（取自素材解析的「考查……」），红色标签，放在【知识点】之后、【易错点】之前 |
| `【考法】` 下的 `!考法 N　标签：内容` | 同【考点】，用在章内小节已经叫「## 考点」的书里（如中考总复习） |
| 讲解区的 `A．…｜B．…` | 例题选项另起一行，自动等距排列 |
| `{{关键词}}` | 完整版加粗主题蓝；背诵版下划线；默写版换成横线 |

表格里不要用「｜」写译文（「｜」会被当成分栏，多出一列），表格和普通段落里的译文写成括号：Everybody knows … （每个人都知道……）。

写法要点：规则、例句、对照表三样分开写，不要把例句接在规则后面同一段；能列成表的（变化规则、缩写、人称代词、主格宾格位置）一律用 `[表]`。

## 练习区（`###` 下面）

| 写法 | 生成 |
|---|---|
| `\| 一棵＿＿＿＿的小松树……` | 练习正文（楷体，首行缩进 2 字）；一行一段 |
| `（有改动）` | 右对齐 |
| `一、读短文，完成练习。（每题 2 分）` | 练习大题（加粗） |
| `1.第 1 自然段的空白处……（2 分）` | 练习小题；普通行都按小题处理 |
| `A.绿茵茵　紧紧　小小　　B.紧紧　小小　绿茵茵` | 选项：按两个以上空格或「｜」切开，自动等距排列 |
| `1.A. Me｜B. I｜C. My｜D. Mine` | 短文选择题：题号和选项同一行，四栏排开 |
| `[横线]` / `[横线2]` | 1 条 / 2 条作答横线（按答案长短给，不要一律一条） |

## 答案区（`# 参考答案` 之后，或章内 `[答案]` 之后）

答案放哪有两种写法：
- 书末集中：`# 参考答案`，下面 `## 第一单元` 分单元
- 每章后面（知识清单 / 语法手册默认）：本章练习后写 `[答案] Unit 1 参考答案`，成品里另起一页、标题同练习标题样式、进目录；到下一个 `# 单元` 为止，里面用 `### Unit 1 基础练习` 分组。`run.py assemble` 默认就这样拼

| 写法 | 生成 |
|---|---|
| `## 第一单元` | 答案单元小标题（红色） |
| `### 一、乡村小学（节选）` | 答案篇名 |
| `1.考点：叠词的理解与运用` | 题号和「考点：」红色加粗 |
| `详细答题思路：先通读句子……` | 标签加粗，正文常规 |
| `参考答案：C` | 标签加粗，答案蓝色加粗下划线 |
| 其他行 | 答案正文 |

## 行内标记

| 写法 | 生成 | 用途 |
|---|---|---|
| `__画线句__` | 下划线 | 题目里的画线词句 |
| `[[加点字]]` | 着重号（字下加点） | 题目里的加点字 |
| `{{关键词}}` | 正常版：原样；背诵版：下划线；默写版：挖空 | 只在讲解区用，标需要背的关键词 |
| `〔S03 p12〕` | 成品里删掉（`--show-sources` 才显示） | 素材出处，每个例题、短文、答案都要有 |
| `【缺】说明` | 构建时报错拦下（`--allow-gaps` 才放行，显示为红字） | 素材里找不到的内容，交给用户补 |
| `<!-- 备注 -->` | 忽略 | 写给自己或用户的备注 |

## 卷面专用（类型: 试卷）

| 写法 | 生成 |
|---|---|
| `[卷头] 2026 秋三年级语文期中测试卷` | 卷名居中 + 「学校 班级 姓名 得分」信息行 |
| `一、积累与运用（30 分）` | 大题 |

## 最小示例

```
# 第四单元（童话王国）
> 读童话，感受童话丰富的想象
## 考点 12：结合文章内容评价童话人物
【常见问法】
1.故事里的××给你留下了什么样的印象？简单写写你的看法。〔S01 p9〕
【答题思路】
找出与角色相关的词句（语言、动作、神态、心理等）+分析角色的形象。
【答题模板】
1.我认为××……（{{聪明机智}}/{{积极乐观}}/孝顺父母/不畏困难等），从××……（做的事情/人物描写等）中可以看出。
例：你认为故事里的青头具有什么样的特点？请简单写写你的理由。（3 分）〔S01 p9〕
| 青头大吃一惊，它一下子蹦到牛身上……
——《在牛肚子里旅行》
答：我认为故事里的青头具有关心朋友、聪明勇敢的特点，从它为了救朋友不顾自己的安危，积极地想办法的行为中可以看出。

### 摇摇摆摆的旅行队〔S02 p3〕
| 一只鸭子队伍出发了。……
（有改动）
1.短文写了鸭子们的一次什么经历？（2 分）
[横线]
2.下列说法正确的一项是（　　）（2 分）
A.小兔子很支持鸭子出门｜B.鸭子们一个月后回来了｜C.狐狸吃掉了短腿太太
```
