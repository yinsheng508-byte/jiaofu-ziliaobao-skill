# 模板：考点答题模板（经典引擎，5 个版本）

适用：小学、初中「有题型、有答法」的专题资料，如语文阅读理解考点与答题模板、作文方法、专项题库、单元试卷；一份内容稿拆出完整版 / 考点模板 / 练习题 / 参考答案 / 背诵默写 5 个版本（用户要哪几个由方案定，`--variants` 选）。

## 怎么用
这个模板用 skill 自带的经典引擎（`scripts/build_docx.py`），**项目里不放 build.py**：
1. `run.py template use 考点答题模板 <项目>`（复制标记写法、版式规范、封面样板到 `2_样张/排版/` 备查）
2. 内容稿按 `标记写法.md` 写；框架选 `资料框架.md` 里的一类
3. `run.py build <项目> [--variants 完整版,练习题] [--engine word]`：出 Word → 回填目录 → 导 PDF → 预览 → 闸门 → 交付检查
4. 版式参数在 `<skill>/config/排版参数.json`（改了全书生效）；要封面就从 `封面样板/` 复制一份到 `<项目>/封面/封面.html` 再改

## 文件
| 文件 | 作用 |
|---|---|
| 标记写法.md | 内容稿标记（文件头、单元 / 考点 / 栏目 / 练习 / 答案 / 行内标记） |
| 经典版式规范.md | 颜色一色一义、元素字号行距、精排检查清单、5 个版本、知识清单主题、封面 |
| 资料框架.md | 考点答题模板、知识清单、专项题库、试卷、背诵默写五类骨架和目录方案示例 |
| 封面样板/ | 3 个书皮式封面（C 酒红推荐） |

## 样章定稿标准（来自已做过的项目）
- 讲解区整段加粗、宋体四号；练习区楷体小四；一色一义（黄框考点、紫问法、绿思路、红模板、蓝答案）
- 考点标签不落页尾；例文和题同页；单元、答案另起页
- 封面要「真实书皮」感，简单干净，不要气泡、数据卡片

## 踩过的坑
- 用户在 Word 里手动改过之后只能 `run.py pdf`，不能再 build（会覆盖）
- Word 和 LibreOffice 分页常差一页：正式 PDF 用 `--engine word`，目录会按 Word 的 PDF 再回填一次
