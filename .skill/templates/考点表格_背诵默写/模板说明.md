# 模板：考点表格_背诵默写

适用：教资、考公、考研、初高中政治 / 道法这类「按考点背诵」的资料，做成考点表格风的笔记（「考点 N」标签 + 考频 / 页码标签 + 红框表格 + 点拨框），一份内容稿出背诵版、默写版两版。参考样式见视觉规范第七节「考点表格风」。

来源：在「知识手册_背诵默写」上改出来的（2026-11 跨模型验收任务：七上道法第一单元，参考两张教资考点笔记截图）。

## 版本
`<书名>（背诵版）`、`<书名>（默写版）`，页码一致，`gates` 核页数。

## 和知识手册模板的区别
| 组件 | 这个模板 |
|---|---|
| 标题层级 | 章（居中大标题）→ 课（左对齐粗体）→ 节（红色粗体）→ @考点 |
| 考点 | `@考点：名 | 标签 ; 标签` → 「考点 N」小标签 + 右侧红色【】标签 |
| 条目 | 一个考点下的普通条目自动合成细红框 |
| 关键词 | 背诵版浅粉底红字（知识手册是红字下划线） |
| 表格 | 细红框线四周 + 内部，表头浅粉底，首列可加粗，空首列自动合并 |
| 点拨 | `[点拨 注意]` 蓝色虚线浅蓝底 |
| 页眉页脚 | 页眉粗细双线；页脚「第 X 页 / 共 Y 页」 |
| 主题 | 样式.json 写 `"主题": "考点表格风"` |

## 怎么用
1. `run.py template use 考点表格_背诵默写 <项目>`
2. 改 `2_样张/排版/样式.json`：书名、封面文字（`封面.通用`，**两版不同的卖点写在 `封面.背诵 / 默写` 里**，它们优先级最高）
3. 内容稿按 `项目规范.md` 写
4. `run.py build <项目>`

## 样章定稿标准（来源项目）
- 一单元一章，课接排，节下直接是考点
- 「考点 N」用浅粉底红字加细框（不用红底白字的实心块，避免 AI 模板味；用户要实心块时改 kaodian()）
- 点拨框只放素材里本来就有的提示，不为了凑样式加

## 踩过的坑
- 填充率不够时：允许大框跨页、把表格格子里的 ①②③ 分成多行，比放大字号好
- 封面模板 HTML 是来源项目的（道法），换学科改 样式.json 的「封面」，版式要变才改 HTML
