# 教辅资料包 Skill

把参考资料、电子课本和你自己整理的资料，用 AI 整合升级成一份更清晰、更完整、更丰富的原创资料产品：Word 精排 + PDF，或者 A4 手写风笔记。

## 下载

点右上角绿色的 **Code → Download ZIP**，解压后得到整个工作文件夹：

```
.skill/      skill 本体（不要动）
输入资料/    你的资料放这里（里面有「新资料包」模板文件夹）
输出项目/    做好的资料包都在这里
```

## 第一次使用

用 WorkBuddy / Antigravity / Claude 桌面端打开解压后的文件夹，对 AI 说：

> 这是我第一次用「教辅资料包」skill，请读取 skill 规范，按里面的安装说明帮我把环境配好。

详细用法见 `.skill/README.md`。

> 手写笔记自带的字体中有几款来自网店打包，商用前请自行确认字体授权。
