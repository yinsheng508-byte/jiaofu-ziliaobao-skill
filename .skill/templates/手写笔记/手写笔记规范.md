# 手写笔记排版规范（A4 打印 / 小红书图文）

把整理好的内容排成「像手写、但工整好读」的笔记，**默认 A4**（方便学习和打印），同时出逐页 PNG。和 Word 版是两条出路：**内容规则完全一样**（references/取材规范.md、内容规范.md、文风规范.md：知识只取素材、标出处、缺的标【缺】、不留原作者信息），只有排版换成这里的手写风。
版式参考了小红书上高赞的手写笔记（横线本、表格框、括号树导图、文言逐字注、卡片稿），做成 23 份样张，需要哪种直接套；表格、下划线、练习题、导图、列表等每种内容形式都有统一规范（第五节）。

| 文件 | 作用 |
|---|---|
| 本文件 | 规范全文 |
| `shortcuts/手写笔记/SKILL.md` | `/手写笔记` 入口（`run.py setup` 复制到 Claude Code 的 skills 目录，并写好 skill 路径） |
| `scripts/handnote.py` | 渲染 + 自动检查（`$RUN note …`） |

## 零、快速开始

```
/手写笔记 <资料路径 | 资料包项目> [版式、纸张、字体、页数、用途]
```

```bash
$RUN note init <项目> <样张编号> [名字]          # 复制样张到 <项目>/2_样张/手写笔记/NN_名字.md
$RUN note <项目>/2_样张/手写笔记/*.md --out <项目>/3_成品/手写笔记    # 每份稿一个文件夹：p-NN.png + <稿名>.pdf + 总览.png + 检查报告.md
$RUN note <稿.md> --pages 2-3 --no-pdf          # 只重出某几页（改样式时用）
$RUN notebook <项目>/2_样张/手写笔记 --name <书名>   # 多章合订：页码连续、答案放章末，合成一本 PDF
```

流程见第七节；和 Word 版一样分三个阶段、只停三次：方案里的手写笔记页面规划（`1_规划/方案.md`，确认点一）→ 第一章手写页（确认点二，样章）→ 交付（`3_成品/手写笔记/`，确认点三，原作者信息清零）。
命令里的 `$RUN` = `python3 <skill>/scripts/run.py`（Windows 用 `python`）。

| **01** | 云游体 | 可爱圆润 | K12 低年级、点阵、便签、四线格英语、封面 |

## 二、颜色（一色一义，全书不变）

| 颜色 | 意思 | 写法 |
|---|---|---|
| 黑 | 正文 | 直接写 |
| **红** | 标签（何时用 / 怎么用）、关键条件、易错、结论 | `**文字**`、`- 何时用：`的「-」自动红 |
| **蓝** | 例题、手写解答、计算过程、简译、答案连线 | `例：` 开头整行自动蓝；`{蓝|文字}` |
| 红色波浪线 | 必背公式、口诀、核心方法 | `~~文字~~` |
| 蓝色直线 | 材料里要圈的时间、主体 | `__文字__` |
| 黄色荧光 | 二三级标题、技巧名、要单独记的一句 | `==文字==`、`### ` |
| 绿色胶囊 | 一级标题 | `## ` |
| 粉色色块 | 章标题 | `# `（色块样式） |
| 紫色虚线框 | 注意 / 反例 / 口诀汇总 | `:::框` |
| 蓝框 / 蓝圈 | 正确选项 | `*B. …` |
| 红圈 | 「坑」「错」「易」这类单字印章 | `{章|坑}` `{圈|字}` |
| 浅粉灰 | 描红（田字格、四线格） | `{描|字}` |

- 绿 / 紫在导图里做层级色；卡片、目录、导图分支用固定轮换色（粉蓝黄绿紫橙青），按顺序自动配，不手选
- 底色（第三节）只改纸，不改这套颜色

## 三、纸张与背景

背景 = **纸张**（决定线、格、质感）× **底色**（整页淡色）× **装饰**（可选）。三者都在手写稿头部写，效果见 `纸张背景总览.png`。

选纸张：
- **要打印给学生写** → 白底 / 康奈尔 / 四线格 / 田字格（线淡、留白多、省墨）
- **知识笔记** → 横线本（默认）；更正式 → 表格框；理科 → 方格 / 网格
- **合集、素材** → 纯色；**导图** → 导图 / 网格；**可爱 K12** → 点阵 / 便签；**文艺** → 牛皮纸
- 一份资料包里纸张 ≤3 种：主体一种 + 导图页一种 + 封面一种

### 3.2 底色（8 种，`底色:`）

奶油 `#fffdf5`（横线本默认）· 纯白 `#fff` · 米黄 `#f8f4ea` · 薄荷 `#f1faf4` · 樱粉 `#fff5f6` · 天蓝 `#f2f7fe` · 牛皮 `#efe4cf` · 浅灰 `#f6f6f4`

- 不写就用纸张自带的；一份笔记一种底色
- 按学科配色时：语文樱粉、数学天蓝、英语薄荷、综合奶油；**打印版优先奶油 / 纯白**（彩色底色打印会发灰）

### 3.3 装饰（`装饰:`，可多选，用「、」隔开）

| 装饰 | 样子 | 用在 |
|---|---|---|
| 活页孔 | 左侧一列打孔，正文右移 | A4 活页本感，打印后真的可以打孔装订 |
| 胶带 | 左上、右上两条和纸胶带 | 封面、合集首页、小红书首图 |
| 页角 | 右下角卷页 | 点缀，一套用 1–2 页 |

- 装饰一页 ≤2 种；正文页一般不加，封面 / 首页 / 小红书图才加
- 不加阴影、渐变、照片背景、大面积插画

## 四、页面（A4）

- **尺寸 A4**：设计尺寸 1080×1527（210×297 等比），PNG ×2 导出 2160×3054（≈260 dpi，打印清楚）；PDF 精确 A4（210×297 mm），整份连页，直接打印
- 要发小红书 3:4：头部写 `尺寸: 小红书`（1080×1440，不出 PDF）
- 页边 60px（≈12 mm），页眉在顶部 22px 处，页码在底部；正文区 ≈ 960×1370
- 横线本行高 56、正文 30px，**所有行都落在横线上**：标题、例题、空行都按整行排；A4 一页约 **24 行**
- 一页一个完整知识块：章节、例题和它的解答不跨页；放不下就在前面加 `===`，**不缩字号、不压行距**
- **每页都要排满、内容丰富**（排版铁律）：只有章节之间新起页时可以留白，其余每页都要填满。长稿子开 `自动分页: 是`（4.1），检查报告列出每页填充率，正文页要 ≥80%（章末页不限）；填不满就补素材里的细节（易错点汇总、例子、对比、快问快答），不放大字号、不加装饰凑
- 页码：横线本 / 方格 / 网格 / 康奈尔 / 四线格 / 田字格「-1-」，纯色 / 点阵 / 牛皮纸「01 / 05」，表格框、白底、导图、便签不要

### 4.1 自动分页与页级设置

- 头部 `自动分页: 是`：渲染时先量出每个块的真实高度，再按页面高度贪心装页；标题不落页尾；插图放不下时自动缩到 ≥75% 放进这页。此时 `===` 只用在章首、需要换纸张的地方（硬分页），其余内容连续排
- 页首写 `@纸张: 网格`、`@底色: 薄荷`、`@留白`：只对这一段生效（`@留白` = 这页允许空，比如章首）
- `起始页码: 7`：多份稿连续编页
- 表格超过一页不会自动拆：长表（如快问快答）拆成几个 `:::表`，每个 ≤5 行，分页器才能填缝

## 五、组件规范（按内容形式）

把**每种内容形式**定好「遇到这种内容怎么排才好看」，直接套。
每类组件的效果样张：`assets/手写笔记/样张/13–20_组件_*.md`（渲染出来看效果），图里灰色小字就是写法。

**通用三条**（所有组件都守）：
1. **一色一义**：颜色意思见第二节，组件里不另起颜色；卡片、导图分支用固定轮换色，不手选
2. **对齐横线**：组件高度是行高的整数倍时最好看；横线本里优先用「行」类组件（列表、标签行、例），块类组件（表、框、导图）上下各留半行
3. **一页一个主角**：一页最多一个大块组件（大表 / 导图 / 一组练习），其余是行；两个大块就分页

### 5.1 标题层级

| 级别 | 写法 | 样子 | 规则 |
|---|---|---|---|
| 页标题 | `# ` | 色块 / 马克笔 / 红字（随版式） | 每页最多一个；≤14 字 |
| 分节飘带 | `#> ` | 两侧撇号 + 粉色胶囊 | 只用在卡片、目录这种「合集」页 |
| 一级 | `## ` | 绿色胶囊，左探出 | 中文序号「一、」 |
| 二级 | `### ` | 黄色胶囊 | 阿拉伯数字「1、」 |
| 三级 | `#### (1) ` | 只有序号带黄底 | 括号数字「(1)」 |
| 副标题 / 单独一行 | `> ` / `^ ` | 居中 | 章节导语、单独成行的公式 |

- 序号体系固定：一、→ 1、→ (1) → ①；同一页不混用
- 标题后至少跟一行内容，不能落在页尾（落了就 `===`）

### 5.2 文字强调（由弱到强 6 级）→ 样张 13

| 级 | 写法 | 用在 | 一页上限 |
|---|---|---|---|
| 1 荧光 | `==文字==` | 要单独记的一句、技巧名 | 4 |
| 2 直线 | `__文字__` | 材料里圈时间、主体（蓝） | 不限（只在材料里） |
| 3 波浪线 | `~~文字~~` | 必背公式、口诀、核心方法 | 5 |
| 4 着重号 | `{着|字}` | 逐字要记、易写错的字 | 2 处 |
| 5 红字 | `**文字**` | 关键条件、结论、标签 | 8（含「何时用」这类标签） |
| 6 圈字 / 印章 | `{圈|坑}` `{章|错}` | 易错提醒、单字 | 2 |

修改与注释：删除线 `{删|错的}`（改错，后面跟正确写法）· 拼音 `{拼|字|pīn}` · 字上批注 `{注|字|注释}` · 小标签 `{签|常考}` · 双下划线 `{双|…}`（极少用）。

- **一处只用一种强调**：荧光 + 红字 + 波浪线叠在同一句上等于没强调
- 强调的是「词」不是「句」：波浪线 ≤12 字，超过就只划关键词
- 拼音、批注会撑高行，横线本里少用，白底版式随便用

### 5.3 列表 → 样张 14

| 类型 | 写法 | 用在 | 规则 |
|---|---|---|---|
| 标签式 | `- **何时用**：…` | 方法类知识点（何时用 / 怎么用 / 注意） | 标签 2–4 字、红色，冒号后一句话 |
| 有序 | `1. …` | 步骤、先后、解题顺序 | 序号黄圆；≤7 条，多了拆两组 |
| 并列要点 | `* …` | 无先后的几条（方法名、短语） | 黑点；每条 ≤15 字 |
| 勾选清单 | `[ ] …` / `[x] …` | 复习打卡、自查 | 勾了的变灰；放页尾 |
| 缩进 | 两个空格开头 | 列表里的下一级 | 最多缩两级 |

- 选择：**有先后用有序，没先后用点，带标签用标签式**；同一组里不混
- 每条一行放得下最好看；放不下宁可拆成两条

### 5.4 表格 → 样张 15

| 类型 | 写法 | 用在 |
|---|---|---|
| 速记表 | `:::表`，无表头 | 一一对应的数值、公式（百化分、单位换算） |
| 标准表 | 第二行 `|---|` 出黄色表头 | 多个对象 × 多个属性 |
| 对比表 | `:::表 对比` | 两三样东西逐项比较，每列一色 |
| 首列表 | `:::表 首列` | 首列是项目名、无表头 |
| 无框表 | `:::表 无框` | 横线本里的轻量对照（口诀、短对应） |
| 浅色表 | `:::表 浅` | 导图页里的补充表 |

- **≤5 列、≤8 行**；超过就拆成两张表或改成列表
- 单元格 ≤8 字自动居中，长文字左对齐；一格不超过两行
- 表头只放名词；数字、公式放单元格里，用 `{分|a|b}` 写分数
- 表格前要有一行说明是什么表（`###` 或一句话），不要让表孤零零开头

### 5.5 练习题 → 样张 16、17、10

| 题型 | 写法 | 规则 |
|---|---|---|
| 选择 | `:::选择`，`1. 题干（ ）` + `A. … *B. …` | 选项按最长那个自动排：≤6 字一行 4 个，≤14 字一行 2 个，更长一行 1 个；`*` 标答案；`:::选择 印` 题干用印刷体 |
| 判断 | `:::判断`，每行末尾写 `√` / `×` | 括号右对齐到行尾 |
| 填空 | `{空|答案}` | 横线长度按答案字数；一行最多 2 空 |
| 连线 | `:::连线`，`左 | 右`，最后 `答案：1-B, 2-A` | ≤6 对；两列各 ≤8 字 |
| 简答 | `:::简答 N`（N = 答题横线行数），`答：…` | 横线数按答案字数估：每 20 字一行，再多 1 行 |
| 例题精讲 | `:::印`（材料）+ `:::例题`（选项 + 手写解答） | 讲解用，不是练习 |
| 计算 | `:::竖式` | 等号对齐 |

- **头部 `显示答案: 否` 出练习页，改成 `是` 再出一遍就是答案页**（答案红色、选择项蓝圈、连线画出、简答写在横线上），两版版面完全一样，方便对照
- 一页练习 ≤8 题；同一题型放一起，题型名用 `## `
- 答案只用素材里的答案（references/取材规范.md），素材没有的标【缺】，不自己补

### 5.6 思维导图与流程 → 样张 18、04

| 类型 | 写法 | 用在 | 规则 |
|---|---|---|---|
| 括号树 | `:::树`，缩进 2 空格一级 | 一章总结、多层分类（≥3 层） | ≤4 层；叶子用「适用：/方法：/例：」开头会自动上色 |
| 发散导图 | `:::发散 中心词`，分支顶格、要点缩进 | 一个主题的几个方面（2 层） | 2–6 支，每支 ≤4 条，每条 ≤10 字；分支自动左右分、彩色曲线 |
| 流程 | `:::流程`，`步骤 | 说明` | 固定步骤、解题流程 | 3–5 步横排；更多用 `:::流程 竖` |
| 时间轴 | `:::时间轴`，`时间 | 事件` | 历史、时政、事件先后 | ≤6 个节点，事件一句话 |

- 选择：**层多用树，层少用发散，有先后用流程，有时间用时间轴**
- 导图一页一个，标题之外不放别的大块；字号比正文小一档（自动）

### 5.7 卡片与提示 → 样张 19、06

| 类型 | 写法 | 用在 |
|---|---|---|
| 概念框 | `:::概念 名词` | 定义、概念、公式名，标签压在框线上 |
| 注意框 | `:::框`（首行「注：」带红点） | 注意、反例、易错汇总 |
| 易混辨析 | `:::辨析 A | B`，每行 `左 | 右` | 两个易混概念逐条对照（左粉右蓝） |
| 便签 | `:::便签`（`:::便签 粉/蓝/绿`） | 小技巧、口诀、记忆法，一页最多 1 张 |
| 金句 | `:::金句 ——出处` | 名言、课文名句、作文素材 |
| 案例卡 | `:::卡片` | 素材积累，一页 3 张 |
| 贴纸 / 印章 | `{贴|包子法}` `{章|坑}` | 点缀，一页 ≤2 个 |

- 提示类组件一页 ≤2 个，挨着放会抢主角
- 卡片内文字 ≤4 行；更长就是正文，不要框

### 5.8 英语词条 → 样张 20

`:::单词` 每行 `单词 | 音标 | 词性 | 释义 | 例句`（例句里 `==词==` 高亮本词）。

- 单词蓝色大号，音标用印刷字体（手写字体没有音标符号），词性红色小胶囊
- 一页 ≤8 个词；短语、句型用 `* ` 并列列表接在后面
- 推荐字体 01（圆润、英文字母好认）

### 5.9 公式、计算与文言

- 分数 `{分|分子|分母}`；单独成行的公式用 `^ ` 居中，必背的加 `~~ ~~`
- 竖式 `:::竖式` 原样保留空格；算式里的乘号统一写「＊」或「×」，一份笔记里只用一种
- 文言逐字注 `:::文言`（5.12 块表），一页 ≤5 句；注释自动红橙交替、上下错开，不用手动调

### 5.10 怎么选组件（速查）

| 内容长这样 | 用 |
|---|---|
| 一个方法 + 何时用 / 怎么用 | 标签式列表 + 例 |
| 几个步骤 | 有序列表（≤7）或流程（3–5，要醒目时） |
| 几个并列名词 | 并列要点，或速记表（有对应关系时） |
| 多对象多属性 | 标准表 |
| 两个东西比较 | 对比表（属性多）/ 易混辨析（逐条说法） |
| 一章所有知识 | 括号树 |
| 一个主题的几个方面 | 发散导图 |
| 有年份的事件 | 时间轴 |
| 定义 | 概念框 |
| 易错、反例 | 注意框 |
| 小技巧、口诀 | 便签（醒目）/ 荧光一句（不醒目） |
| 名句 | 金句 |
| 题目材料原文 | `:::印` |
| 练习 | 第 5.5 节对应题型，配答案页 |

### 5.11 插图 `:::图`（理科笔记的主角）

```
:::图 植物细胞 整 宽=66 [挖空]
图名：植物细胞结构模式图〔S1 p4〕
:::
:::图 动物细胞 左 宽=48          ← 左图右文：块里其余行是图旁文字
- 细胞膜：控制物质进出
:::
```

- 图文件：`<手写稿目录>/图/<名字>.svg`，找不到再找 `assets/手写笔记/插图/`；图多时按学科写一个生成脚本放在 `<项目>/手写笔记/图源/`，统一画法和配色
- 画法统一：深灰线稿 + 淡彩平涂，不写实、不抖动；标注用 `<text class="lab">` + 细引线，引线拉到图右侧对齐；图名写在图下
- 标注字号固定 26px，不随图缩放（渲染时按宽度自动换算）
- `挖空`：标注换成红色 ①② + 横线，做识图自测；`显示答案: 是` 时恢复标注
- 图高自动吸附到整行，上下各留半行，正文继续落在横线上
- 一页一张大图；小图（步骤条、示意）可与表、列表同页
- **图一律自己画 SVG，不截课本、教辅里的图**：截图分辨率低（课本 PDF 约 96ppi）、带出版社页眉和水印，教辅 docx 里的图常是旧版教材的。课本图只用来核对结构
- **科学上要对**：每张图画完逐个结构对课本核一遍——部件位置、相对大小、有没有不该挡住的东西（玻片挡住通光孔这种错一眼就会被看出来）
- **引线不交叉、不穿过别的结构**：右边放不下就把一部分标注挪到左边
- **步骤图和口诀一一对应**：一个字一格（如「擦滴撕展盖染吸」7 格），格里的动作和字对得上，工具不压编号
- 同类事物全书同色（例：植物绿、动物粉、微生物蓝紫、细胞核紫），写进生成脚本当常量

### 5.12 写法总表

#### 行内

`**红字**` · `==荧光==` · `~~波浪线~~` · `__直线__` · `[[蓝框]]` · `{蓝|…}` `{红|…}` `{绿|…}` `{紫|…}` `{橙|…}` `{灰|…}` · `{印|印刷体}` · `{分|分子|分母}` · `{章|坑}` · `{贴|包子法}`（云朵贴纸）· `{空|答案}`（挖空）· `{粉|…}`（粉底）· `{点}` `{红点}` · `{箭}`（→）· `{着|字}` 着重号 · `{圈|字}` 圈字 · `{删|…}` 删除线 · `{双|…}` 双下划线 · `{拼|字|拼音}` · `{注|字|注释}` · `{签|标签}` · `` `原样` ``（灰色小字原样显示，写说明用）

其他块：`:::选择` `:::判断` `:::连线` `:::简答 N` `:::发散 中心` `:::流程 [竖]` `:::时间轴` `:::概念 名词` `:::辨析 A | B` `:::便签 [粉/蓝/绿]` `:::金句 出处` `:::单词`，写法见 5.2–5.8；行：`1. ` 有序、`* ` 并列、`[ ]` / `[x]` 清单。

#### 块（`:::名字` 开头，`:::` 结尾）

| 块 | 内容写法 | 效果 |
|---|---|---|
| `:::印` | 一行一段，可混 `__时间__` `~~重点~~` | 半透明白底印刷体，像贴在本子上的题目材料 |
| `:::例题` | `A. …` 选项一行一个，正确项前加 `*`；其余行是解答 | 左列印刷体选项（正确项蓝框）+ 右列蓝色手写解答 |
| `:::框` | 一行一条；第一行以「注：」开头会在框外加红点 | 紫色虚线框 |
| `:::竖式` | 保留空格对齐的计算 | 蓝色手写竖式 |
| `:::表` | `| a | b |`，第二行写 `|---|` 就是表头；`:::表 浅` 用浅绿细线 | 手写感表格（速记表、对照表） |
| `:::树` | 每级缩进 2 个空格；`>` 开头是挂在节点下的方框补充 | 左括号树思维导图，层级绿紫交替 |
| `:::卡片` | 第一行「编号 标题」，中间正文，`启示：` 一行 | 彩色序号 + 柔边胶囊标题 + 正文 + 启示标签 |
| `:::目录` | `说明：…` 一行（可选），之后 `标题 | 页码` | 彩色序号 + 点线 + 页码 |
| `:::文言` | 每句三行：原句（`[词](注释)` 注字、`|` 断句）、`——《出处》`、`简译：…`；句间空一行 | 粉底句子带 + 字下括号注释（红橙交替、上下错开）+ 红色断句线 + 蓝色简译 |
| `:::封面` | `小字：` `标题：`（`/` 分两行）`副标题：` `标签：a|b|c` `署名：` | 封面 / 首图 |

行首前缀（特殊纸张用）：`字 ` 田字格一行（一字一格，全角空格留空格，`{描|字}` 描红）· `en ` 四线格一行英文（`en [空行]` 留一行空白）。

## 七、流程

### 7.1 项目结构

```
<项目>/                              ← 资料包项目（结构见 SKILL.md「项目文件夹」）
  进度记录.md
  1_规划/   素材/ 素材清单.md 素材覆盖表.md 原作者信息.txt 方案.md   ← 方案里写手写笔记的页面规划（确认点一）
  2_样张/   内容稿.md（和 Word 版共用）
            手写笔记/ 01_封面.md 02_第一章知识点.md …   ← 手写稿（一份稿 = 一个版式，可多页）
  3_成品/   手写笔记/<稿名>/ p-NN.png  <稿名>.pdf  总览.png  检查报告.md
            手写笔记/<书名>_合订本.pdf                ← 多章合订（notebook）
            交付说明.md  检查/交付检查报告.md          ← 确认点三
```

### 7.2 步骤（只停三次）

1. **定内容**：已有内容稿（check 通过）直接用；没有就按 SKILL.md ②~⑤ 做到 check 通过。**内容只来自素材**
2. **确认点一：在 `1_规划/方案.md` 里写手写笔记的页面规划**（下面这张表），和目录一起交；交付形式、范围、改写程度没定的也在这里问。方案逐章逐节列知识点和出处、全书图清单（哪些挖空），先做哪章当样章、为什么：

   ```
   # 手写笔记方案：<标题>
   用途：A4 打印 / 小红书　共 N 页　纸张 <主体> + <导图页>　字体 09　底色 奶油　装饰 无
   | 页 | 稿 | 版式（样张号） | 内容（对回内容稿） | 素材 |
   |---|---|---|---|---|
   | 1 | 01_封面 | 08 | 标题、4 个标签 | — |
   | 2–4 | 02_知识点 | 01 | 第一章 一~三 | S01 p2–5 |
   | 5 | 03_导图 | 04 | 第一章总结 | 同上 |
   | 6–7 | 04_练习 | 16/17 | 第一章练习 8 题 + 答案页 | S02 p1 |
   缺口：【缺】……
   ```

3. **写第一章手写稿**：`$RUN note init <项目> <样张号> <名字>`，删掉样张内容，按第五节组件规范改写：
   - 每个知识点拆成「标题 → 何时用 / 怎么用 → 例」，一行 ≤30 字，长句拆行
   - 题干、材料原文放 `:::印`；讲解、解答手写；**解答、答案只用素材里的**
   - **出处〔Sxx pN〕写在稿子里**（例 / 题 / 材料块的上一行或行尾），渲染时自动去掉，不上图；检查报告会列出没标出处的块
   - 先按一页 ≈24 行写满再 `===` 分页（或开 `自动分页: 是`）；练习稿出两遍（`显示答案: 否 / 是`，另存 `_答案.md`）
4. **出图、改到干净**（最多三轮）：`$RUN note <项目>/2_样张/手写笔记/*.md --out <项目>/3_成品/手写笔记`；读每份《检查报告.md》，❌ 必改、⚠️ 逐条判断；逐页看 PNG（第八节人工清单），改稿重出
5. **确认点二：第一章样章**发给用户看；调整意见改到第一章上，定下的标准写进《进度记录.md》「样章定稿标准」。用户说「不用看样章」就跳过，写进进度记录
6. **铺开其余章节**：照样章标准做完，中间不再停；每章做完更新进度记录
7. **交付检查**：`$RUN audit <项目>`，原作者信息 error 清零（手写稿里的字和稿名、PDF 文字、文件名都查；PNG 里的配图看图核对）
8. **确认点三：交付**（第九节）

### 7.3 知识点笔记的结构与做法

- **知识点从教辅素材里取，课本只做参考**：素材之间、素材和课本说法冲突时以课本为准；课本有、素材没有的只在方案里列出来问用户
- **新旧教材**：素材常混着旧版说法。以新教材为准改术语（如 营养组织→薄壁组织）；新教材删掉、但考试还会碰到的，标【拓展】，不当主线
- **一章的固定结构**（每章新起页）：
  1. 章首页（`@留白`）：本章导图 + 本章实验 / 主线 + 本章必背几条
  2. 各节：概念 → 图 → 表 / 对比 → 口诀，一节一个主图
  3. 章末复习：知识树 → 易混辨析 → 识图自测（`挖空`）→ 快问快答 → 本章易错点汇总
- **样章默认第一章**：跑通图、组件、分页；第一章太简单、代表不了全书时，换图最多、最难排的一章，在确认点一就说清楚
- **学生版 / 答案版**：答案版不手写，由学生版头部加 `显示答案: 是` 生成（每次改学生版都重新生成）；两版**分页必须一样**，某题答案太长把答案版撑多一页，就换题或删题
- **补内容填页时**，不能把同页挖空题、快问快答的答案写出来；补的每条也要有出处

## 八、检查

### 8.1 自动检查（每次出图都跑，写进《检查报告.md》）

| 项 | 级别 | 怎么改 |
|---|---|---|
| 手写字体没加载上（回落成系统字体） | ❌ | 字体文件重新用 fontTools 修 |
| 某页内容超出 | ❌ | 在那页加 `===` 挪到下一页；不缩字号 |
| 页尾最后一行是标题 | ⚠️ | 标题挪到下一页 |
| 红字 >8、波浪线 >5、荧光 >4 | ⚠️ | 删掉次要的强调（5.2） |
| 提示类组件 >2（框、便签、金句、概念、贴纸、印章） | ⚠️ | 合并或删 |
| 大块组件 >1（≥4 行的表、导图、流程、时间轴、词表） | ⚠️ | 分页 |
| 正文页填充率 <80%（`@留白` 页、章末页不算） | ⚠️ | 补素材里的易错点、对比、快问快答；不放大字号、不加装饰凑 |
| 例 / 题 / 材料块没标〔Sxx〕 | ⚠️ | 补出处，素材没有写【缺】（只在稿子里出现过〔S…〕时检查） |

### 8.2 人工检查（逐页看 PNG）

1. 字体真的是手写；同一页只有一种手写字体
2. 每行坐在横线上，没有半行错位；四线格字母坐在红线上；田字格字在格中间
3. 没有压页脚、出外框；页尾没有孤零零一两行
4. 颜色意思和第二节一致；强调没有叠用
5. 例题选项和解答对齐，正确项有蓝框；**解答、答案和素材一致**
6. 分数、竖式、拼音没有挤坏行高
7. 文言注释不互相压字；断句线在字缝里
8. 卡片标题一行放得下（超长缩短标题，不缩字号）
9. 组件选得对（5.10 速查表）
10. 练习页和答案页版面一致
11. A4 PDF 页数 = PNG 张数，没有多出空白页
12. 每张插图科学上对（对课本核结构），引线不交叉；挖空图的答案没在同页别处露出来
13. 封面只写真实信息，不写「全网最全」「名师」「必考」这类说不实的词
14. 页眉、角标、贴纸、印章、配图里没有原素材的作者名、机构名、系列品牌、水印和二维码

## 十、不要做

- 不做「假手写」特效：不加抖动、歪斜、墨渍滤镜，参考图的好看来自工整 + 一色一义
- 不在一页里混 2 种以上手写字体、2 种以上纸张；一份资料包纸张 ≤3 种
- 不给每段都加贴纸；贴纸、印章一页最多 2 个；装饰一页 ≤2 种
- 不缩字号、不压行距去塞内容；放不下就分页
- 不用生图模型画整页（文字会错）；只用这里的 HTML 渲染
- 不自己编例题、答案、案例；素材没有就【缺】
- 不截课本、教辅里的图放进笔记；图自己画（5.12）
- 不为凑满一页编内容；填不满就补素材里有的
- 不留原素材的作者名、网名、机构 / 店铺名、系列品牌、水印、二维码和引流话术（references/质检与交付.md 第三节）
