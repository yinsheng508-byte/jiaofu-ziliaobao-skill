# /手写笔记

「教辅资料包」skill 的手写笔记分支入口。

## 先找到 skill 目录

- `<skill>` = `<SKILL_DIR>`（`run.py setup` 安装时换成本机的实际路径；还是尖括号占位符说明没装好，让用户重跑 setup）
- 命令：`python3 <skill>/scripts/run.py note ...`（Windows 用 `python`），下文记作 `$NOTE`；其他子命令记作 `$RUN`

**动手前读**：`<skill>/templates/手写笔记/手写笔记规范.md`（规范全文，第七节是流程）、`<skill>/references/取材规范.md` 和 `内容规范.md`（内容规则）。三个确认点的细节见 `<skill>/SKILL.md`。

## 核心原则（细则见 templates/手写笔记/手写笔记规范.md）

1. **内容只取素材**：知识点从教辅素材里取，课本只做核对；素材没有就【缺】，不编
2. **每页排满**：只有章首等新起页能留白，正文页填充率 ≥80%；填不满补素材里的易错点、对比、快问快答，不放大字号凑
3. **配图自己画、画对**：不截课本或教辅的图；每张对课本核结构，引线不交叉，挖空图答案不在同页露出
4. **先方案、再样章、后铺开**：样章默认第一章，用户看过再做其余，中间不再停
5. **学生版 / 答案版分页一致**：答案版由学生版加 `显示答案: 是` 自动生成，改一次重生一次
6. **不留原作者信息（红线）**：手写稿、页眉角标、配图、文件名里不能有原素材的作者名、网名、机构 / 店铺名、系列品牌、水印、二维码和引流话术；名字记在 `1_规划/原作者信息.txt`，交付前 `$RUN audit <项目>` 清零

## 参数

`/手写笔记` 后面跟的东西原样当输入：

| 用户给的 | 怎么处理 |
|---|---|
| 已有资料包项目（`输出项目/<日期>_<标题>/`，里面有《内容稿.md》） | 直接取内容稿，跳过收素材 |
| 资料文件 / 文件夹（PDF、Word、图片、txt） | 先 `$RUN new <资料>... --title <标题>` 入库编号 |
| 直接贴的文字 | 存成 `输入资料/<标题>/原文.txt` 再入库 |
| 版式、纸张、字体、底色、页数、用途（打印 / 小红书） | 记下；没说的按手写笔记规范.md第六节「选版式」默认 |

什么都没给时，只问一句：「要整理哪份资料？（给路径或项目名）」。

## 流程（只停三次）

1. **定内容**：项目已有内容稿就用；没有就按 SKILL.md ②~⑤ 做（素材入库 → 原作者信息屏蔽词 → 覆盖表 → 内容稿，每段标〔Sxx pN〕，缺的标【缺】）
2. **确认点一：在 `1_规划/方案.md` 里写手写笔记的页面规划**：共几页、每页用哪个版式（手写笔记规范.md第六节编号）、纸张 / 字体 / 底色、每页放哪些内容、是否出练习页 + 答案页；开工时没说清的范围、改写程度一起问
3. **写第一章手写稿**：`$NOTE init <项目> <样张编号> <名字>` 复制样张到 `<项目>/2_样张/手写笔记/`，按手写笔记规范.md第五节组件规范改写；出处〔Sxx pN〕留在稿子里（不上图）
4. **出图、改到干净**：`$NOTE <项目>/2_样张/手写笔记/*.md --out <项目>/3_成品/手写笔记`；读每份《检查报告.md》，❌ 必改、⚠️ 逐条判断；再逐页看 PNG（手写笔记规范.md第八节），最多三轮
5. **确认点二：第一章样章**：调整意见改到第一章上，定下的标准写进《进度记录.md》「样章定稿标准」。用户说「不用看样章」就跳过，写进进度记录
6. **铺开其余章节**：照样章标准做完，中间不再停；每章做完更新进度记录
7. **交付检查**：`$RUN audit <项目>`，原作者信息 error 清零
8. **确认点三：交付**：A4 打印 PDF + PNG 的完整路径、每份几页、内容来自哪几份素材（用素材编号，不写原作者名）、哪些是【缺】、交付检查结果、字体授权提醒
