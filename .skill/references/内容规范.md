## 一、产品定位：整合升级

用户给参考资料、电子课本和自己整理的资料，我们用 AI 的整合能力把它们升级成一份**新的资料产品**：比任何一份原素材都**更清晰**（结构、层次、重点）、**更完整**（几份素材互相补全）、**更丰富**（例子、对比、易错、记忆方法齐全）。

AI 的价值在「整合」和「呈现」，不在「编」：知识、数据、题目、答案都来自素材和课本（取材规范第一节）。

## 二、整合升级具体做什么

| 动作 | 做法 | 例 |
|---|---|---|
| 重组结构 | 按课本顺序或参考的结构重新搭章节；同类合并 | 三份资料各讲一半，合成一章完整的 |
| 互相补全 | 取最完整的一份做主体，其他份补它没有的说法、例子、易错点、真题 | S01 有定义、S03 有例子、课本有原图，合到一起 |
| 统一表述 | 同一个概念全书用同一种说法（以课本为准）；用词、编号、标点统一 | 「薄壁组织」不再和「营养组织」混用 |
| 重新讲清楚 | 用老师讲课的话重写讲解，短句、分点，比原素材好懂；事实不变 | 一大段课本原文拆成「是什么 → 有什么特点 → 怎么考」 |
| 提炼归纳 | 把散在各处的内容归纳成表、导图、时间轴、口诀、易错汇总；**归纳里的每一项都要能在素材里找到** | 把 4 种细胞结构做成对比表 |
| 标重点、分层次 | 必背标 ★ 或 `{{}}`；考情、考频标出来（素材有才写） | 「【全背】【25 下选择】」 |
| 出版本 | 同一份内容稿出背诵版、默写版、答案版等（方案定） | — |

**改写档位**（取材规范第九节）：默认「整合升级」；用户要求「只排版」或「轻整理」时按那一档，不做重写和归纳。

## 三、丰富度：宁多勿漏

**覆盖率**：方案里的每个知识单元，都要把**所有素材里关于它的内容**收进来，包括规则、例外、易错、口诀、例子、真题。题目解析里藏着的规则也要收进讲解，素材的讲解部分往往只占一小半。

**每个知识单元的构件**（素材里有就必须放，没有不编）：

| 构件 | 说明 |
|---|---|
| 核心内容 | 定义、要点、原句、公式（课本为主干） |
| 关键词 | 必背的词标 `{{}}`（背诵版红字，默写版挖空） |
| 例子 / 例题 | 每个要点至少一个，素材有就放 |
| 易错点 | 素材和解析里提到的易混、易错 |
| 口诀 / 方法 | 素材有的直接用；可以把素材里的要点编成口诀，但口诀里不能出现素材没有的事实 |
| 图 / 表 | 能对比的做表；课本有图的配图 |
| 拓展 | 超出本册的放「拓展」，和主线分开 |
| 考情 | 考试类资料：题型、分值、考频、真题出处（素材有才写） |
| 练习 + 答案 | 按方案 |

**写薄了的硬标准**（命中就回素材补）：
- 一个知识单元只有一两句话，素材里明明有更多
- 解析里的规则没收进讲解
- 能做成表的对比内容还是大段文字
- 正文页填充率 <80%（`gates` 会报；章末页不限）

填不满时补**素材里有的**细节：易错汇总、例子、对比表、快问快答。不放大字号、不加装饰、不编内容凑。

## 四、准确：按学科验证

| 学科 | 验证方法 |
|---|---|
| 理科（数学、物理、化学） | 答案代回题目验算；单位、数字逐个核 |
| 文科（语文、历史、道法、地理、生物知识点） | 和课本逐句核：数字、年代、人名地名、术语 |
| 英语 | 答案逐条和素材比对（`$RUN verify`）；例句能在素材里找到（`$RUN qa sources`） |
| 考试类（教资、考公、考研） | 考点、真题年份、分值对回素材 |

- 新旧教材：以用户的版本为准，旧说法改掉或放拓展
- 归纳表、口诀、导图做完后，逐项回素材核一遍
- 每章跑 `$RUN gates <项目>`：它去出处标的页里找关键词和数字，找不到的逐条人工核

## 五、结构

- 按教材单元 / 章节，或按参考的结构；一级标题另起一页
- 编号、栏目、每章的结构在样章定稿后固定，后面各章照做
- 目录到二级（必要时三级），页码由脚本回填

## 六、练习与答案

- 题目、答案、解析默认按题号原样取；用户要原创题时按取材规范第九节改编
- 答案和题一一对应，题数和答案条数一致（`check` 核）
- 学生版题干不透露解法；答案、解析放答案版或章末，按方案
- 讲解里用过的题练习里不再出现；同一道题全书只收一次
- 分值、选择题括号位置全书统一

## 七、版本之间

- 所有版本从**同一份内容稿**由脚本生成，不分别手写
- 背诵版和默写版、学生版和答案版**页码必须一致**（挖空用同宽），`gates` 核
- 分册和完整版逐字一致

## 八、写完自查（每章，结果写进进度记录）

- [ ] `$RUN check <项目>` 无 error
- [ ] 每块都有出处；【缺】列进进度记录
- [ ] 对照第三节构件表，素材里有的构件都放了
- [ ] 归纳表、口诀逐项回素材核过
- [ ] 随机抽 5 处回素材核，全对
- [ ] 挑三段读出声，没有说明书腔（文风规范）
