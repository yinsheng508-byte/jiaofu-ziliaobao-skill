# 卖点挖掘

目标：用户只给一个产品主题（如「三年级上册语文同步练习」「考研英语单词书PDF」「小学数学口算题卡」），我们自己找出 3 张图能讲清楚、能促成下单的卖点。

## 1. 先定人群与场景（写进卖点说明.md）
- 谁买：学生本人 / 家长 / 老师 / 上班族……
- 什么时候买：开学前预习、期中期末复习、寒暑假衔接、考前冲刺、备课……
- 怕什么：版本对不上、内容太散、打印糊、买了没答案、链接失效、发货慢。

## 2. 查同类（WebSearch，2–4 次即可）
搜索词示例：`<主题> 小红书 资料`、`<主题> 电子版 淘宝 详情`、`<主题> 家长 推荐 整理`、`<主题> 痛点 / 避坑`。
记录：同类商品标题高频词、详情页常见卖点、评论里反复出现的需求和抱怨。把有用的链接写进「参考来源」。

## 3. 候选卖点分类（每类至少想 1 个）
| 类别 | 例子 |
|---|---|
| 内容覆盖 | 全科/全册打包、按单元同步、重难点全覆盖、附期中期末卷 |
| 结构好用 | 一页一个知识点、思维导图、背记清单、分色标注、目录可跳转 |
| 配套齐全 | 答案版+空白版、讲解+练习、音频/视频、错题本模板 |
| 形式方便 | 高清 PDF、A4 直接打印、平板/手机可看、可反复打印 |
| 交付服务 | 24 小时自动发货、网盘永久链接、汇总链接多选项、持续更新 |
| 信任背书 | 店铺已售/好评（只用用户给的数据）、笔记同款、原创整理 |

## 4. 选与排
- 封面：标题 = 「年级/对象 + 产品核心名」，一句话卖点 = 最强的内容卖点，3 条卖点 = 最能打动买家的三点（内容/配套/好用），不放注意事项。
- 第 2 张固定是购前须知（`notice`），不放卖点。
- 第 3 张卖点展示二选一：`points`「为什么选这份」——痛点→解决，3–4 条，每条标题 ≤12 字、说明 ≤22 字，有内页图就放 1–3 张；或 `grid`「内容一览 / 包含哪些」，6–8 个模块（内容多、模块清楚的产品用它）。

## 5. 红线
- 不编造具体数字（页数、份数、销量、提分）、教材版本、名师名校背书。
- 不用极限词：最、第一、唯一、顶级、100%、保过、必考、官方、权威。
- 「原创作品 倒卖必究」「不支持任何编辑修改」只在电子资料类使用。
