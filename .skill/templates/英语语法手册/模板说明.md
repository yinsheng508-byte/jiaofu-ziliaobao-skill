# 模板：英语语法手册（知识清单 + 分层练习）

适用：素材是「题 +【答案】+【解析】」的解析版 Word 卷子（同步练习、单元精练、刷题本）时，按章取题拼稿，做成「语法知识清单 + 基础 / 提升分层练习 + 章末答案」。七上、八上、九年级、中考总复习、四到六年级英语都用这个做过。

## 怎么用
和考点答题模板共用经典引擎（内容稿写 `类型: 知识清单`，自动套知识清单主题），**项目里不放 build.py**：
1. `run.py template use 英语语法手册 <项目>`
2. 按 `取题流程.md` 一章一章做：`qa stems` 看题干 → 写 `选题配置/<章>.json` 和 `<章>_讲解.md` → `assemble` 拼稿 → `verify` 核答案 → `qa scan / sources` 自查
3. 讲解写法见 `../考点答题模板/资料框架.md`「英语语法手册」和 `../考点答题模板/标记写法.md`「知识清单专用」
4. `run.py build <项目> --variants 完整版 --engine word`

## 文件
| 文件 | 作用 |

| 取题流程.md | 每章 9 步、选题配置写法（kind、可选项）、哪些题不收、出处怎么标 |

## 样章定稿标准（来自已做过的项目）
- 每个语法点：课本原句 → 口诀 → 知识点（一条规则一个小标题，规则 / 例句 / 对照表分开）→ 考点 → 易错点 → 拓展
- 每章练习：基础约 20–25 题、提升约 20–25 题；章末另起页放本章答案
- 知识点要讲细讲全：解析里的规则逐条收进讲解

## 踩过的坑
- 讲解里引用的句子正好是某道练习的答案时，把那道题从练习里撤掉
- 表格里不要用「｜」写译文（会多出一列），译文写成括号
