# 输入资料怎么放

每做一份资料包，在这里建一个文件夹（把「新资料包（复制这个文件夹，改成资料包名称）」复制一份，改成资料包名称，如「八上生物知识手册」），里面三个子文件夹：

| 文件夹 | 放什么 | 用来做什么 |
|---|---|---|
| 1_教材课本 | 教材或电子课本 | 核对内容：以课本为准 |
| 2_对标资料 | 收集的对标资料、你自己整理的资料 | 内容来源 |
| 3_参考版式 | 想要的排版样子（图片或文档） | 只看版式，不取内容 |

放好后在 Claude Code 里说：「把 输入资料/<资料包名称> 做成资料包」。
原文件不会被移动或修改；三个文件夹里的 放什么.txt 不用删。
