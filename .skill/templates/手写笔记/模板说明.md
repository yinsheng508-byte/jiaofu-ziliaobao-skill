# 模板：手写笔记（A4 打印 / 小红书 3:4）

适用：把整理好的内容排成「像手写、但工整好读」的笔记：知识点笔记、例题精讲、思维导图、文言逐字注、背诵挖空、错题本、英语抄写、生字练习等，出逐页 PNG + 可打印 A4 PDF；多章可以合订成一本。

## 怎么用
手写笔记用 skill 自带的渲染引擎（`scripts/handnote.py`，HTML 渲染，是唯一不走 Word 的模板）：
1. 动手前读 `手写笔记规范.md`（第零节快速开始、第七节流程）
2. `run.py note init <项目> <样张号> <名字>` 复制样张到 `<项目>/2_样张/手写笔记/`（23 份样张见规范第六节）
3. `run.py note <项目>/2_样张/手写笔记/*.md --out <项目>/3_成品/手写笔记`
4. 多章成书：`run.py notebook <项目>/2_样张/手写笔记 --name <书名>`（页码连续、答案放章末，合成一本 PDF）

## 资源
样式、6 款手写字体、23 份样张、样张效果图在 `<skill>/assets/手写笔记/`。字体随包自带、不用装；有几款商用要自己确认授权。

## 样章定稿标准（来自已做过的项目）
- 正文页排满（≥80%），章首、章末页可以留白（写 `@留白`）
- 知识点从参考资料里取，课本只核对；配图自己画 SVG、对课本核结构
- 不分学生版 / 答案版时，题里留编号空，答案放每章末（`答案: 章末`，合订命令会自动写）
