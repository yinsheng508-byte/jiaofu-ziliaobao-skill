# 取题流程（解析版 Word 卷子）

适用：同步练习、单元精练、刷题本这类「题 +【答案】+【解析 / 详解 / 分析】」格式的 docx / PDF。这类素材**不手写内容稿**，按本流程一章一章取题拼稿。
原则：**题目、答案、解析一律按题号原样取，不手抄、不改字**；格式问题（空、选项、标点）交给脚本，素材笔误用 `fix` 改，并记进素材覆盖表。

## 一、每章怎么做（一章做完、自查完再做下一章）

1. **看题干**：`$RUN qa stems <项目> S13 22 308`（素材编号、起止行号）。逐行列出题号行、选项和【答案】，跳过解析。各份素材的题型行号先记进《进度记录.md》，换会话不用重找
2. **挑题**：按第三节「不收」清单排除，写 `选题配置/<章键>.json`；每层（基础、提升）约 20–25 题
3. **写讲解**：`选题配置/<章键>_讲解.md`（写法见 ../考点答题模板/资料框架.md「英语语法手册」、标记写法.md「知识清单专用」）；第一章的文件带全书文件头。没有练习的章（如书末附录）只写讲解、不写 json，assemble 时照样带上键名
4. **拼稿**：`$RUN assemble <项目> starter unit1 … <本章>`（每次把已完成的章都带上，生成整本内容稿）
5. **核答案**：`$RUN verify <项目> starter unit1 … <本章>`，必须打印「全部一致」
6. **自查**：`$RUN qa scan <项目>`（空数、选项、故选、看图、重复）、`$RUN qa sources <项目>`（讲解英文例句能否在素材找到）、`$RUN qa grep <项目> S14 关键词`（核讲解中文说法）
7. **出图看版面**：`$RUN build <项目> --variants 完整版`，逐页看新章节；`$RUN qa pages <项目>` 查孤页和目录页码
8. **记录**：本章的取舍、素材更正追加进《素材覆盖表.md》；查到并已改的、按判断没收的、不收的题各几处写进《进度记录.md》，交付时一起告诉用户

第一章做完就是确认点二的样章；之后每章自查完直接往下做，不停下来等用户。

## 二、选题配置（`选题配置/<章键>.json`）

```json
{"groups":[
 {"title":"Unit 5 基础练习","sections":[
  {"head":"一、单项选择","sid":"S13","label":"一、","kind":"items","from":22,"to":308,
   "join":[1,4,16],"pick":[1,4,7,9,10,13]}]},
 {"title":"Unit 5 提升练习","sections":[
  {"head":"二、用所给词的适当形式填空","sid":"S12","label":"二、","kind":"items","from":145,"to":275,"pick":[1,2,10]},
  {"head":"五、翻译句子","sid":"S12","label":"题型一 ","kind":"items","from":276,"to":452,"lines":1,"pick":[34,36]}]}
]}
```

- `groups[].title`：练习分组标题，写成「<章> 基础练习 / 提升练习」，答案区按同样的分组排
- `head`：成品里的大题名（自己按题型起，不一定照素材）；同一大题接着取另一份素材时写空字符串
- `sid`：素材编号；`label`：出处前缀，和题号拼成〔S13 一、7〕。同一份素材里两个题型题号会重的，label 要能区分（如「二、」「翻译 」）
- `from` / `to`：素材 txt 里这个题型的行号范围，**从第一道题的行号开始**（前面带编号的讲解行会把第 1 题并进去，取题时报 KeyError）
- `pick`：按素材题号取，顺序就是成品顺序，成品题号自动连续

**kind（题型格式）**

| kind | 素材长什么样 | 例 |
|---|---|---|
| `items` | 每题后面自带【答案】【解析】 | 单选、填空、翻译 |
| `batch` | 题目在前，一行【答案】51．What time 52．How long… 集中给；有词框 `[表格]` 时自动取成框 | 选词填空 |
| `passage` | 一篇短文带编号空，后面 1-10 题选项，答案集中 | 语法选择、完形 |
| `passage`（无选项） | 短文填空：正文里「   1    (impress)」编号空，【答案】可以另起一行「1．has impressed  2．him」，【导语】作总解析、后面按题号给解析；出处自动标在短文末尾 | 中考专项、复习讲义的 Passage |
| `endkey` | 题目只有题号，答案集中在卷末「一、1. xx 2. xx」或「1-5.DCACB」（不带点也认）；配 `ans_from` / `ans_to`（卷末答案的行号） | 单元语法巩固练习 |
| `cloze` | 课文挖空「1.____(feel)」，答案在文末一行一个；配 `ans_from` / `ans_to`，空号接本组题号往下排 | 课文语法填空 |

**可选项**

| 配置 | 作用 | 什么时候用 |
|---|---|---|
| `lines: 1` | 每题后加作答横线 | 翻译、连词成句（原题没有作答行时） |
| `hint_blank: true` | 在括号提示词前补空 | 原文的空是下划线格式，抽字后丢了 |
| `lead_blank: true` | 行首的空抽字后只剩空格（「      for you?」），在行首补空，空长随原文；items、endkey 都能用 | 完成句子、改一般疑问句 |
| `fix: {"9": {"D, There has": "D．There has"}}` | 按题号改素材笔误（只改格式和明显笔误） | 每处都写进素材覆盖表 |
| `ansfix: {"20": "10"}` | 集中答案行里写错或会被切错的答案，按题号写全文 | passage / batch / endkey；答案里有「half past 6.」这类会被当成题号切开的 |
| `ansgroup: {"51": "is；across from"}` | 答案按空分组显示 | 一条长空填几个词，答案词数和空数对不上 |
| `split_items: [7]` / `ans_sep: "single"` | batch 答案的拆分方式 | 两个空的答案写在一起 |
| `ans_cut: "。"` | endkey 的答案后面跟着解析（「1.cut 。祈使句用动词原形。」），按这个符号切开，前半是答案、后半进「解析：」 | 卷末答案带解析 |
| `ans_letter: true` | endkey 卷末答案是「2.D 句意:……」：字母作答案，后面进「解析：」（verify 只比字母） | 专练 PDF |
| `join: [1, 4]` | 短的一问一答排成一行（中间两个全角空格）；endkey 里是两行的一问一答并成一行 | 回收孤页；只合加起来一行放得下的（长句并了也会折行，先估长度） |
| 组上的 `"break": true` | 这一组（基础 / 提升）另起一页 | 练习只差几行就溢出时，配合挪题回收孤页；只有提升练习的章放在第一组 |

**脚本自动做的（不用配置）**
- 取题：清页码行；分行选项合并；「全角+空格+全角」算一个空，空长随原文；短文空用不换行空格；同题出现第二个【答案】视为孤立题干丢掉；去掉【分析】【详解】【点睛】标签
- endkey：去掉单选题号前的「( )」「（　）」、翻译题下的「-」占位行；对话的「-」「--」换成「—」；题号重复（「1.Your bike」实为 21）或题号缺点（「8 The old」）的题自动丢掉
- 拼稿：统一标点（只改标点不改字）：中文后的英文问号冒号逗号换全角、英文逗号分号句号后补空格、选项字母统一「A．」、解析里的箭头换顿号

## 三、哪些题不收（每处记进素材覆盖表）

| 情况 | 怎么认出来 | 处理 |
|---|---|---|
| 看图题 | 解析里有「图片」「如图」「看图」「钟表上显示」 | 不收 |
| 划线提问 | 题目要求「对划线部分提问」 | 抽字后看不出划线部分，不收 |
| 题干丢了空 | `qa stems` 里题干没有空、答案却有内容；空只剩几个半角空格 | 能用 `hint_blank` / `lead_blank` 补回就补，否则不收 |
| 答案错位、孤立答案 | 两个【答案】挨着、答案和题意对不上 | 不收 |
| 解析本身讲错 | 解析的规则说法和讲解矛盾 | 不收（不替素材改解析） |
| 解析有机器腔 | 【解析】里有「首先」「其次」，被机器味检查拦下 | 换题，不改解析 |
| 翻译题中英不符 | 中文「祖父母」对英文 My parents | 不收 |
| 超出本册范围 | 过去时、完成时、宾语从句、分数等 | 不收；对应知识放讲解【拓展】 |
| 和课本说法冲突 | 日期顺序、美式英式 | 以课本为准，冲突的题不收 |
| 重复题 | 两份素材同一道题；和前面章节重复 | 只收一次（`qa scan` 会提示开头相同的题） |
| 讲解里用过的题 | 例题、易错点引用的题；讲解里的句子正好是某道练习题的答案 | 练习里撤掉（每章跑 `qa sources`，找不到原句的逐条核：多半是自己编的或是练习答案） |
| 题目要求缺失 | 同义句改写题没写「（同义替换）」 | 换素材里写了要求的同一题，或不收 |
| 括号里没有提示词 | 放在「用所给词的适当形式填空」下面却没给词 | 换到合适的大题，或不收 |

## 四、出处怎么标

- 练习和答案：脚本自动标〔S13 一、7〕（素材编号 + label + 题号）
- 讲解：标在语法点、小标题、易错点行末，如〔S12 一；S13 1（1）〕〔S14 讲解三〕；**讲解出处写「讲解」二字**，不要写成「S14 三、2」这种会和练习题号混淆的样子
- 课本：〔S01 p64〕（扫描件页码）；课本 Grammar Focus 的填空题课本没有答案，不替它补答案，只收完整的句子
