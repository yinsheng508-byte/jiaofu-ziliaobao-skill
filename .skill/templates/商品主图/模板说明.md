# 商品主图 / 详情图（/商品主图、/主图）

适用：小红书等店铺的虚拟商品主图和详情图（3:4，1242×1656），教辅资料、电子书、考证考研资料、课程、PPT / 简历 / 表格模板、素材包都能用。固定出 3 张：**01 商品主图 → 02 购前须知 → 03 卖点展示**。

目录
- 一、输入和输出位置
- 二、主图模板（配色）
- 三、三张图分别放什么
- 四、流程
- 五、版式规则（防 AI 味）
- 六、隐去关键信息（红线）
- 七、自检清单

---

## 一、输入和输出位置

```
/商品主图 <产品主题 或 资料包项目> [店铺名] [资料文件] [补充说明]
```

| 情况 | 输出到 |
|---|---|
| 给的是资料包项目（`输出项目/<日期>_<名称>/`） | `<项目>/3_成品/主图/`：资料页直接取 `3_成品/` 里的 PDF |
| 只给产品主题或几个文件 | `输出项目/<日期>_<产品主题>_主图/`：`spec.json`、`卖点说明.md`、`assets/`（资料页图）、`01.png`–`03.png` |

**店铺名必须由用户每次提供**：没给就只问一句「店铺名称写什么？」。不要猜，不要沿用别的项目的店名，**不写进 skill、模板、偏好文件**，只写在这一次的 spec.json 里。

## 二、主图模板（配色）

```bash
$RUN mainimg templates          # 列出主图模板
```

| 模板 | 风格 | 适合 |
|---|---|---|
| 经典蓝框红字（默认） | 蓝外框 + 红色特黑大标题，最醒目 | 中小学教辅、合集、各类电子资料 |
| 清新绿框 | 墨绿外框 + 橙红标题 | 小学同步、地理生物、自然科学 |
| 学术藏青 | 藏青外框 + 正红标题，稳重 | 考研、考公、教资、大学课程、职业资格 |
| 暖橙活力 | 暖橙外框 + 深红标题 | 寒暑假衔接、口算练习、低年级趣味资料 |
| 粉色温柔 | 玫粉外框 + 红色标题 | 家长向、幼小衔接、手账模板 |

效果图在 `assets/主图模板/效果图/`。模板只管配色和底部条默认文字，版式是同一套；spec.json 写 `"模板": "清新绿框"` 套用，`theme` 可以再细调。用户要新配色时，复制一个模板 json 改颜色另存（颜色只用 外框色 / 标题红 / 深灰 / 白 四类）。

## 三、三张图分别放什么

| 张 | 类型 | 放什么 | 不放什么 |
|---|---|---|---|
| 01 商品主图 | `cover` | 左：深色小字（年级 / 学科 / 对象）→ 红色超大标题（2 行，每行 2–4 字）→ 3 条最强卖点（每条 ≤10 字）；右：「笔记同款」胶囊 + **一页真实资料**；底部条：发货方式 + 卖点短语 + 版本 | 注意事项、下单必看 |
| 02 购前须知 | `notice` | 关于商品 / 关于发货 / 如何获取 / 关于退款 四段；不写 `sections` 用内置文案（百度网盘版），交付方式不同就改对应句子 | 卖点 |
| 03 卖点展示 | `points` 或 `grid` | `points`「为什么选这份」：3–4 条痛点 → 解决，可配 1–3 张内页；`grid`「资料内容一览」：6–8 个模块，内容多的产品用它 | — |

合集链接（多本一个链接，如小四门）：主图展示位放各册正文首页拼成 2×2，`subjects` 写科目方块，第 3 张用 `grid` 逐本列出单元 / 页数这类真实数据。

spec 字段写法见 [spec格式.md](spec格式.md)，完整示例 `示例/spec-example.json`。

## 四、流程

1. **收集输入**：店铺名（必须问）；资料页：用户给了 PDF / 截图就用真实页面，资料包项目就用 `3_成品/` 里的 PDF：
   ```bash
   $RUN mainimg pages <资料.pdf> <输出目录>/assets 6     # 前 6 页转 200dpi 图片
   ```
   挑封面页或版面最好、信息最密的一页放主图展示位，另挑 1–3 页放第 3 张。.docx / .pptx 先导出 PDF。用户没给资料：问一句要不要给一页；说没有才用仿资料封面（`product.cover`）占位，交付时提醒换真实页面
2. **挖卖点**（自己做，不让用户写）：按 [卖点挖掘.md](卖点挖掘.md)，先定人群和场景，再查同类商品，筛 6–8 个候选、选最能打的。资料包项目优先用 `1_规划/方案.md` 和 `3_成品/交付说明.md` 里的真实信息（页数、版本、章节）
3. **选主图模板**：按第二节选，写进 spec
4. **写 spec.json**：标题越短越大；卖点 3 条；底部条按真实交付方式写（百度网盘 / 夸克网盘 / 邮箱）
5. **渲染**：
   ```bash
   $RUN mainimg <输出目录>/spec.json
   ```
6. **自检**（第七节），有问题改 spec 重跑，最多 2 轮
7. **交付**：写《卖点说明.md》（目标人群、选用卖点及理由、备选卖点、待确认事项、参考来源）；把 01–03.png 发给用户，一句话说每张讲什么，列出待确认事项

## 五、版式规则（防 AI 味）

- 外框纯色不渐变，内板纯平不加阴影；卡片纯白纯平
- 标题纯色红 + 特黑字体，**不描边、不投影、不渐变**
- 全图只用 外框色 / 标题红 / 深灰 / 白 四类颜色；字体只用特黑（标题、店铺名、小标题）+ 苹方 / 微软雅黑（说明文字）
- 左栏和右侧资料卡上下对齐
- 每张图强调不超过 3 处：`[[文字]]` 外框色底白字，`{{文字}}` 红色强调，`**文字**` 加粗
- 特黑字体只有常用汉字、数字、基本标点：标题、卖点、页签里**不用 ★ ✓ ① 这类符号**
- 字少、字大、一眼看懂：宁可删字也不缩小字号
- **资料页图片不拉伸、不裁切、不压缩**，按原比例贴合（脚本已保证）

## 六、隐去关键信息（红线）

- **店铺名**：只来自用户这一次的输入，不写进 skill、模板、偏好、示例
- **原作者信息**：主图里展示的资料页必须是**我们自己的成品**（已过 `audit`），不能放原素材的页面（带原作者名、水印、二维码、店铺名）；用户给的同行截图只作参考，不能直接放进图里
- **不编造事实**：页数、份数、版本年份、教材版本、销量、好评、「名师」「状元」只用用户给的或资料里真实有的；拿不准写通用表述（「同步新教材」），列进《卖点说明.md》的「待确认」
- **不用极限词和违规词**：最、第一、唯一、顶级、100%、保过、提分 XX 分、必考、官方、权威
- 「原创作品 倒卖必究」「不支持编辑」只用在电子资料类；可编辑的模板类商品不写「不支持编辑」

## 七、自检清单（逐张用 Read 看图）

1. 资料页完整、没变形、清晰（脚本提示分辨率偏低就换高清图重转）
2. 字没有溢出、重叠；标题够大够醒目
3. 卡片撑满，没有大块空白（太空就补说明或换 `grid`）
4. 没有错别字；强调没超过 3 处
5. 店铺名是用户这次给的；图里没有原作者信息、没有极限词
6. 数字都是真实的，拿不准的已列进「待确认」
