# 北京市本土素材案例汇编
#> 一、首都功能与国际交往
:::卡片
001 北京重大活动集散保障：分批到达与交通协同
2025年9月3日，北京为4万余名观礼人员设置49个远端集结点，先按近端安检能力和站台承载安排分批到达，再用地铁、公交协同转运；散场时分四批、每批间隔10分钟撤离，全部人员在50分钟内完成转场和疏散。
启示：大规模服务不能只靠加车加人，而要把安检、运输、落客、疏散等环节串成完整流程。
:::
:::卡片
002 “入京通 GO BEIJING”：入境服务的多语种集成入口
2026年，北京上线“入京通 GO BEIJING”平台，集成打车、酒店预订、景点购票、支付、导览等39项服务，支持16种语言，并连接国际钱包等支付方式。
启示：城市服务不只是单项功能齐全，更要让初次来访者找得到入口、看得懂信息、办得成事情。
:::
:::卡片
038 北海“国家会客厅”：日常开放与专项接待的空间转换
北海公园探索“平特结合”，日常向游客开放相关园林空间、展示园林文化，专项接待期间再转换为相应服务场所；漪澜堂修缮开放等举措，让保护、开放与接待功能相互衔接。
启示：公共空间多功能利用，关键不在用途多少，而在于何时开放、如何转换、由谁保障要安排清楚。
:::
