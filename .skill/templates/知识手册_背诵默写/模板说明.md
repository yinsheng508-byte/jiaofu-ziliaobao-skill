# 模板：知识手册（背诵版 + 默写版）

适用：按课本章节整理的知识点手册，一份内容稿同时出「背诵版」（关键词红字下划线）和「默写版」（关键词原位挖空，页码和背诵版一一对应）。初中小四门（生物、地理、历史、道法）期末复习、教资 / 考研背诵手册都能用。

已用这个模板做过的：八上生物学、八上地理（两本都用本模板重新生成过，和原成品逐字节一致）。

## 版本
- `<书名>（背诵版）.docx / .pdf`
- `<书名>（默写版）.docx / .pdf`
两版从同一份内容稿生成，页码一致由脚本保证（`gates` 会核页数）。

## 文件
| 文件 | 作用 |
|---|---|
| build.py | 内容稿 → 两个 Word；`--pdf` 时用 Word 导出 PDF、回填目录页码、拼封面 |
| 样式.json | 书名、颜色（≤5 种色相）、字号行距、框的种类、标题细节、目录提示语、封面文字 |
| 样式库/ | 现成的学科样式：生物青碧、地理墨绿。换学科时复制一份改主色和框 |
| 项目规范.md | 内容稿标记写法（写内容稿前必读） |
| 封面/封面模板.html + 封面.py | 背诵版、默写版两张封面；文字全在 样式.json「封面」里改（书名、学科、年级、教材版本、卖点、章节一览），HTML 只在要换版式时改 |
| 裁图.py 网格.py 图框.py 手工裁图.py 查图.py | 从课本 PDF 里取插图的工具（见下） |

## 怎么用
1. `run.py template use 知识手册_背诵默写 <项目>`
2. 改 `2_样张/排版/样式.json`：书名、封面文字、主色（从 `样式库/` 挑一个最近的复制过来改）、框的种类（如生物「知识拓展 / 科学方法 / 易错点」，地理「读图技巧 / 记忆口诀」）
3. 内容稿按 `项目规范.md` 写，开头文件头写 `页眉: 八年级上册 · 生物学知识手册`
4. 插图放 `2_样张/排版/插图/`，文件名 `M_p<页>_<图名>.png`，内容稿里用图名引用
5. `run.py build <项目>`：出 Word → Word 导 PDF → 回填目录 → 封面 → 预览 → 闸门 → 交付检查

## 课本插图怎么取（需要 poppler；Windows 用 winget 装）
| 工具 | 做什么 |
|---|---|
| 裁图.py | 课本页图里自动找图、按图注命名，输出到 `课本插图_全部/` |
| 网格.py | 给课本页加 5% 网格，方便定手工裁图的坐标 |
| 图框.py | 列出课本页里的位图框坐标 |
| 手工裁图.py | 按 `手工裁图.tsv`（页 x0 y0 x1 y1 图名）裁到 `插图/` |
| 查图.py | 列出内容稿用到的插图和来源 |
自动裁常把组合图拆碎，用手工裁图补；图里不能留页眉页码和出版社标识。

## 样章定稿标准（来自已做过的项目）
- 每章新起页，每节新起页；章首不放横幅图
- 每节：节标题 → 知识点（### 一、…）→ 条目（1. 标签：内容）→ 表、图、框按需穿插
- 「课本拓展」只放取自课本旁栏、阅读材料的内容；取自其他资料的叫「知识拓展」
- 框按需加，不是每节都要；一页 ≤2 个
- 样式要轻、像人工精排，但**关键词、条目标签、表格首列的加粗必须保留**

## 踩过的坑
- 课本里没有答案的空白练习表不收
- 自动裁图会拆碎组合图，要手工补
- Word 导出 PDF 偶尔失败：按版本分开重跑（`run.py build <项目> --only 默写`）
- 历史（时间轴 `>` 行）、道法（问答 `? ★问题 @P2` 行）在各自原项目里有扩展写法，本模板还没收；没有时用表格代替，或照原项目的 build 脚本把组件加进项目的 build.py
- 每节很短时把 样式.json「细节.节.另起页」改成 false（节接排，避免大片空白）；闸门会跟着改用章作分界算填充率
- 素材是纯文本（没有页码）时，出处标到课或行号：〔S01 第1课〕〔S02 L120〕
