# 安装配置（首次使用时让 AI 照着做）

**用法**：解压后用 Claude Code 打开「教辅资料包制作 skills」文件夹，说一句：

> 按 .skill/references/安装配置.md 帮我把环境配好

AI 读到这份文档后按下面的顺序做：判断系统 → 装 Python → 跑 `setup` → 按自检结果补齐系统软件 →（用户要的话）配置知识库上传 → 试跑。需要用户亲手做的（输入电脑密码、装 Office、填 OCR 令牌）停下来说清楚怎么做，其余自己做完。

## 给 AI 的总要求

- 先判断系统：macOS 还是 Windows，后面只做对应那一栏
- 命令里的 `<skill>` = `.skill` 文件夹的绝对路径；路径里有空格和中文，**一律加引号**
- `python3` 是 Mac 的写法；Windows 一律写 `python`
- 每装完一样就重跑 `doctor` 看结果，不要一口气装完才看
- 安装软件前先告诉用户要装什么、为什么；要输电脑密码、管理员授权的，让用户自己点
- 用户的令牌、密码不写进 skill 里的任何文件
- 做完后用一段话告诉用户：装了什么、哪些可选的没装、还差什么要他自己做

## 一、要准备的东西

| 东西 | 干什么用 | Mac | Windows | 必须？ |
|---|---|---|---|---|
| Python 3.10+ | 跑所有脚本 | 终端运行 `python3 --version` 看有没有；没有到 python.org 下载 | python.org 下载，安装时勾选「Add python.exe to PATH」；或 `winget install -e --id Python.Python.3.12` | 必须 |
| python-docx、Pillow、pypdf、pypdfium2 | 生成 Word、拼图、读写 PDF | `setup` 自动装 | `setup` 自动装 | 必须 |
| Microsoft Word（或 WPS） | 导出正式 PDF；用户在里面精排 | 用户自己装 Office | 用户自己装 Office | 强烈建议 |
| LibreOffice | 预览、目录页码定位 | `brew install --cask libreoffice`，或官网下载 | 有 Word 可以不装；要装：`winget install -e --id TheDocumentFoundation.LibreOffice` | Mac 必须 |
| poppler | PDF 抽字、转图（更准） | `brew install poppler` | `winget install -e --id oschwartz10612.Poppler`；装不上也能用 | 建议 |
| Chrome 或 Edge | 封面、手写笔记渲染 | 装 Chrome | 系统自带 Edge 就行 | 必须 |
| 手写笔记字体 6 款 | 手写笔记 | **随包自带**（`assets/手写笔记/字体/`），不用装 | 同左 | 自带 |
| PaddleOCR MCP | 扫描件、图片识别 | 见第四节 | 见第四节 | 可选 |
| 思源宋体 | Word 讲解区更好看 | 见第五节 | 见第五节 | 可选 |

Mac 上 `brew` 命令要先有 Homebrew：没有的话让用户按 https://brew.sh 首页那一行命令装好（要输电脑密码）；用户不想装 Homebrew 时，LibreOffice 到官网下载安装包，poppler 跳过（脚本会自动改用 pypdf / pypdfium2）。

## 二、装 Python 依赖和快捷指令（setup）

Python 装好后运行（Windows 把 `python3` 换成 `python`）：

```bash
python3 "<skill>/scripts/run.py" setup
```

它会做四件事：
1. 用当前这个 Python 装 python-docx、Pillow、pypdf、pypdfium2（系统 Python 不让装时自动换方式重试；还不行就把 PDF 相关的包装进 `<skill>/.venv`）
2. 把 `/手写笔记`、`/商品主图`、`/主图` 快捷指令复制到用户目录下的 `.claude/skills/`，并写好本机的 skill 路径（已有同名的旧 skill 会被替换）
3. 建好 `输入资料/`（含说明和「新资料包」模板文件夹）、`输出项目/` 两个文件夹
4. 跑一遍环境自检

提示「找不到 python / python3」：先装 Python，**关掉终端重新打开**再跑。
skill 文件夹挪了位置、或者换了新版本 skill 之后，重跑一次 `setup`（快捷指令里写的是绝对路径）。

## 三、看自检结果，逐项补齐

单独跑自检：

```bash
python3 "<skill>/scripts/run.py" doctor
```

| 自检里的 ❌ / ⚠️ | Mac 怎么处理 | Windows 怎么处理 |
|---|---|---|
| python-docx / Pillow / pypdf / pypdfium2 未安装 | 重跑 `setup`；还不行看它打印的 pip 报错 | 同左 |
| pdftotext、pdfinfo、pdftoppm（poppler） | `brew install poppler`；不装也行，会自动改用 pypdf / pypdfium2 | 不装也行；要装用第一节的 winget 命令，装完重开终端 |
| LibreOffice | `brew install --cask libreoffice` 或官网下载 | 有 Word 时不用管；否则装 LibreOffice |
| Microsoft Word | 用户自己装；没有就让用户用 WPS 手动另存 PDF | 同左 |
| Chrome / Edge | 装 Chrome | 一般自带 Edge；没有就装 Chrome |
| 手写笔记字体缺 | 包没解压完整，重新解压 | 同左 |
| /手写笔记 快捷指令未装 | 重跑 `setup` | 同左 |
| PaddleOCR MCP ⚠️ | 可选，素材有扫描件时按第四节接 | 同左 |
| 排版字体文件 ❌ | 系统字体被删了才会出现，一般不会 | 确认系统有「宋体」「楷体」 |

全部 ✅（OCR 那项可以是 ⚠️）就算配好了。

## 四、OCR（扫描件识别，可选）

素材里有扫描版 PDF、拍照图片时才需要。没接也能用，AI 会看图手录（慢）。

1. 装 `uv`
   - Mac：`curl -LsSf https://astral.sh/uv/install.sh | sh`
   - Windows：`powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`
2. 用户自己去百度 AI Studio 拿访问令牌：AI Studio → PaddleOCR → API 页面「使用我的 AI Studio 访问令牌」。**令牌让用户自己粘贴，AI 不要替他登录**
3. 接入（把 `<你的令牌>` 换成用户给的）：

```bash
claude mcp add-json paddleocr '{"type":"stdio","command":"uvx","args":["--from","paddleocr-mcp","paddleocr_mcp"],"env":{"PADDLEOCR_MCP_MODEL":"PaddleOCR-VL-1.6","PADDLEOCR_MCP_PPOCR_SOURCE":"aistudio","PADDLEOCR_MCP_AISTUDIO_ACCESS_TOKEN":"<你的令牌>","PADDLEOCR_MCP_AISTUDIO_POLL_TIMEOUT":"600"}}' -s user
```

   Windows 的 PowerShell 对单引号里的 JSON 处理不一样，出错时让用户在 `%USERPROFILE%\.claude.json` 的 `mcpServers` 里手动加同样的内容
4. 新开一个 Claude Code 会话生效；`claude mcp get paddleocr` 显示 Connected 即可

## 五、字体说明

- **手写笔记字体**：6 款 ttf 在 `assets/手写笔记/字体/`，渲染时直接从文件加载，**不用装进系统**，Mac、Windows 一样。其中几款来自网店打包，**商用前要自己确认授权**（templates/手写笔记/手写笔记规范.md 第一节）
- **Word 讲解字体**：Mac 用系统自带的 Songti SC / Kaiti SC，Windows 自动换成 SimSun（宋体）/ KaiTi（楷体），都不用装
- **思源宋体（可选）**：免费，粗体比系统宋体好看。到 https://github.com/adobe-fonts/source-han-serif/releases 下载 SourceHanSerifCN，双击安装；再把 `config/排版参数.json` 里 `fonts.serif` 和 `fonts.windows.serif` 都改成 `Source Han Serif CN`
- **封面标题字体（可选）**：封面样板写的是「方正大标宋」，没装会自动换成系统宋体，效果略差但能用；有正版授权的可以自己装

## 六、上传到知识库（可选，用户要才配）

成品做完可以自动传到飞书知识库或 ima 知识库。**都要用户自己配置账号**，AI 不替用户登录、不保存令牌。

**飞书知识库**
1. 装飞书 CLI（npm 包 `@larksuite/cli`，命令叫 `lark-cli`）：先装 Node.js，再 `npm install -g @larksuite/cli`；Mac、Windows 一样。装好后 `lark-cli --help` 能看到说明
2. 用户自己登录授权：`lark-cli auth login`，按提示在浏览器里确认（需要知识库和云空间权限）
3. 问用户要上传到哪个知识库、哪个节点，记进偏好文件
4. 验证：`lark-cli auth status` 显示已登录

**ima 知识库**
1. 用户在 ima 官方渠道拿到 MCP 接入方式和自己的密钥
2. 按官方说明用 `claude mcp add` 接入（密钥让用户自己粘贴）
3. 新开一个 Claude Code 会话，确认 ima 的工具出现
4. 问用户要上传到哪个知识库，记进偏好文件

没配置的，交付时写「未配置」，不影响其他步骤。

## 七、试跑一遍（确认真的能用）

**1. 手写笔记**（用自带样张出一页，验证浏览器和字体）：

```bash
python3 "<skill>/scripts/run.py" note "<skill>/assets/手写笔记/样张/01_横线本_知识点.md" --out "<skill>/../输出项目/_试跑"
```

`输出项目/_试跑/` 里有 PNG 和 PDF，检查报告里没有「手写字体没加载上」就对了。

**2. 素材入库**（用一段文字建个小项目）：在 `输入资料/_试跑/` 里新建 `试跑.txt`，写几行任意内容，然后：

```bash
python3 "<skill>/scripts/run.py" new "<skill>/../输入资料/_试跑" --title 试跑
```

能生成项目文件夹和《素材清单.md》就说明入库正常。完整的 build 要先写内容稿，等第一个真实项目再走。

试跑完删掉 `输出项目/_试跑`、`输入资料/_试跑` 和刚建的试跑项目。

## 八、常见问题

| 现象 | 原因和办法 |
|---|---|
| Windows 终端里中文乱码 | 先运行 `chcp 65001`；脚本本身已按 UTF-8 读写 |
| Windows 提示 `python` 不是命令 | 安装 Python 时没勾「Add python.exe to PATH」：重装勾上，或改用 `py` |
| Mac 看不到 `.skill` 文件夹 | 访达里按 Cmd+Shift+. 显示隐藏文件 |
| Word 导出 PDF 卡住或失败 | 先手动打开一次 Word，关掉首次启动的弹窗；Mac 第一次会弹「允许控制 Word」，让用户点允许 |
| 手写笔记字体没加载上 | 字体文件不完整：重新解压；新加的字体要先用 fontTools 修（手写笔记规范.md 第一节） |
| /手写笔记 不出现 | 重跑 `setup`，再新开一个 Claude Code 会话 |
| 挪了 skill 文件夹后出错 | 重跑 `setup` |
