## 一、红线：知识不编

这个 skill 做的是**AI 原创的资料产品**：结构、表述、归纳方式可以原创，**知识本身不能原创**。

- 每一个知识点、数据、年代、定义、题目、答案、图，都要能对回来源
- 来源里没有的标【缺】交给用户，不自己补，哪怕「常识上肯定是这样」
- 课本练习的空白处、表格空格，素材里没答案的不替它填

## 二、三类输入和优先级

| 输入 | 是什么 | 用来做什么 |
|---|---|---|
| **电子课本 / 教材** | 官方教材 PDF | 概念、定义、原句、插图的**第一依据**；和别的说法冲突时以它为准 |
| **参考资料** | 用户发的同行成品、截图、讲义、真题 | 内容来源（考点、例题、易错、口诀）+ **版式和结构的参照** |
| **用户自己的资料包** | 用户之前整理过的资料 | 内容来源；用户的习惯写法优先保留 |
| 网上找的资料（用户同意后） | 能抓到原文的网页 | 补充来源，只收原文 |
| AI 自己的知识 | — | **不能当内容来源**，只用来发现「素材可能错了」，再去核对或问用户 |

## 三、入库：不同资料怎么取

用户的资料放在 `输入资料/<资料包名称>/` 的三个子文件夹里：`1_教材课本/`（核对用）、`2_对标资料/`（内容来源）、`3_参考版式/`（只看版式）。

```bash
$RUN new 输入资料/<资料包名称> --title <资料包名称>     # 追加：$RUN add <项目> <资料>...
```

课本先编号，《素材清单》类型里标「（课本）」「（对标资料）」；参考版式拷进 `1_规划/参考/`，不入库、不当内容来源。

每份资料编号 S01、S02…，抽字到 `1_规划/素材/S01_xxx.txt`（每页前有「===== 第 N 页 =====」），清单在《素材清单.md》。入库同时把可疑的原作者信息写进 `原作者信息.txt` 的候选区（质检与交付第三节）。

| 资料长什么样 | 怎么取 |
|---|---|
| 有文字层的 PDF、Word | 脚本抽字；抽完挑 2–3 页和原图比对 |
| 扫描件、照片、图片 PDF（状态「需看图」） | 第五节 OCR，逐页看原图校对 |
| 抽字乱码、多栏、表格、勾选框 | 以原图为准，OCR 或手录重排 |
| 解析版 Word 卷子（题 +【答案】+【解析】） | 不手抄，按 `templates/英语语法手册/取题流程.md` 用脚本取题 |
| 截图类参考 | 用 Read 逐张看；只作版式参考的存进 `1_规划/参考/`，不入库 |
| 网页 | 第十一节 |

入库后**逐份读完全部素材**，填《素材覆盖表.md》：每份覆盖哪些章节 / 考点，有没有例题、练习、答案，质量怎样；几份讲同一内容时，记下哪份最完整、各自独有什么。这张表是后面「整合升级」的底稿。

## 四、电子课本怎么拿

- 中小学课本优先用「国家中小学智慧教育平台」的官方电子版；用户可以用开源工具 tchMaterial-parser 下载（粘贴课本预览页网址即可）
- 确认版本：出版社、年份、册次和用户的教材一致（如「人教版 2024 秋 七上」），写进需求单
- 课本放进 `输入资料/<资料包名称>/1_教材课本/`，建项目时自动先入库（编号最前）
- **没有电子课本时**：方案里写明「内容以参考资料为准，未对照课本」；正文里的课本页码只能取自素材，标「课本 P12（待核）」或干脆不写；目录或封底加一句「课本页码取自配套资料，请对照手头课本使用」；交付汇报里提醒用户对一遍课本

## 五、扫描件 OCR

**先 OCR、再看图校对**，不从头手录。接入方法见 安装配置.md 第四节。

- **用哪个**：PaddleOCR MCP（工具 `paddleocr_vl`，模型 PaddleOCR-VL-1.6）；公式、表格特别多的可以试 MinerU
- **怎么调**：`input_data` 给页图**绝对路径**；`return_images: false`；`output_mode` 用默认 `simple`；逐页传
- **慢且限额**：一页约 1.5 分钟，每天有页数上限；能直接抽出字的页不送 OCR
- **OCR 只是初稿**：每页用 Read 看原图逐行对，重点核题号、选项字母、数字、标点、大小写、上下标；对完才算入库；认不出的字标【缺】，不猜
- **已知会乱的**：勾选框选项表会被拆成一列、顺序打乱；图片里的字不识别。按原图重排或手录
- **写回**：按页写进同名 .txt，页首加「（OCR：PaddleOCR-VL-1.6，已看图校对）」
- **不能用时**：退回看图手录，《素材清单》状态写「手录」，不停下来等

## 六、图片怎么来（按优先级）

| 情况 | 做法 |
|---|---|
| 课本 / 资料里有现成的图，图本身清楚 | **先从 PDF 提取原图**；提不出来按图框高分辨率裁切；去掉页眉、页码、水印和周围的字 |
| 图模糊、水印擦不掉、或要统一风格（手写笔记） | 照原图结构**重画**（SVG），画完逐个结构对原图核 |
| 地图、实验装置、细胞结构这类科学图 | 只能取原图，或严格照原图重画，**不能凭印象画** |
| 来源里没有图 | 不加；需要的话写进方案问用户 |

- 图注照原图写；图放在讲它的那段文字旁边
- **不用 AI 生图模型画内容图**（文字、结构都会错）
- 取自课本「思与学」这类栏目的框才叫「课本拓展」，取自其他资料的叫「知识拓展」

## 七、出处和【缺】

- 内容稿里每一块（知识点、例题、练习、答案、图、归纳表）都标出处：〔S03 p12〕；整合了几份就标几份〔S01 p6；S03 p2；课本 p32〕
- 标在这一块的标题行或第一行末尾；成品里自动删掉；`gates` 会去标的那一页核关键词和数字
- 素材是纯文本、没有页码时，标到课或行号：〔S01 第1课〕〔S02 L120〕
- **出处写在正文行里**，写在 `<!-- 注释 -->` 里的不算（check 看不到）
- 内容稿里说明素材时**只写编号**（S01、S02），不写素材原名：原名常带原作者、公众号或店铺名，会被屏蔽词拦下
- 标准确到具体是哪一份：整合了几份就都写上；`gates` 会去标的那份素材里核数字、关键词和句子片段，标错了会被报出来
- 脚本取的题自动标〔S13 一、7〕
- 找不到的写【缺】+ 说明缺什么：「【缺】第六单元第 4 篇练习的答案，S02 只有题没有答案」
- 交付前不能有「无出处的块」；【缺】要么用户补，要么用户同意删

## 八、素材有错时

| 情况 | 例子 | 处理 |
|---|---|---|
| 算式、答案算错 | 「6×9﹣12=32」 | 换一道对的，没有就整题不收；不偷偷改对 |
| 答案错位、缺一半 | 四-2 照抄了四-1 的答案 | 整题不收 |
| 素材之间、和课本矛盾 | 说法不同、新旧教材术语不同 | 以课本为准；都不是课本的只写双方都认的部分，或问用户 |
| 明显笔误 | littel、「D, There has」 | 改掉，记录 |

每一处都写进《素材覆盖表》「质量 / 问题」一列。

## 九、改写档位（方案里必须写明）

| 档位 | 能做 | 不能做 |
|---|---|---|
| **整合升级（默认，AI 原创产品）** | 按新结构重组；多份素材互相补全；用自己的话重新表述讲解；提炼归纳；把内容做成对比表、导图、口诀、记忆法、易错汇总；标重点、分层次；出多个版本 | 编知识点、数据、年代；改题目和答案的意思；新口诀和新表格里出现素材没有的事实 |
| 轻整理 | 原样保留为主，只重排、合并去重、改通顺 | 改写表述 |
| 只排版 | 改格式；修错别字（要记录） | 增删任何内容、加标签、改标点、补表头 |

题目默认取素材原题。用户明确要「原创题」时，可以基于素材的知识点改编（换数字、换情境），答案必须能从素材推出并验算，标〔改编自 S03 p12〕。

## 十、版权

- 「整合升级」后的产品，结构和表述是新的，不整页照搬任何一份素材
- 出版社电子书（有 ISBN）、大机构网课原文不直接搬；拿不准的在覆盖表里标出来问用户
- 课本插图只用于学习资料整理，去掉出版社标识；分发、商用前由用户判断
- 练习短文改动过的标「（有改动）」

## 十一、网上找资料（用户同意后）

- 中文教辅用 WebSearch 的 `mode: extended`，可以限定 `allowed_domains`（sohu.com、21cnjy.com、qq.com、163.com 等）
- 找到的页面抓原文，自己抽正文存成 .txt，第一行写「来源：URL」，放进 `输入资料/<专题>/` 再入库；**不用摘要当素材**
- 图片地址加密、答案被截断的页面，里面的题不收
